# 软件设计师（中级）基础知识速记（数据结构）

## 9.1 基本概念与时间复杂度

**一、4 种逻辑结构**

| 结构 | 关系 |
|---|---|
| 集合 | 无关系 |
| 线性结构 | 一对一 |
| 树型结构 | 一对多 |
| 图状 / 网状结构 | 多对多 |

**二、2 种存储结构**

- **顺序存储**：地址连续，用相对位置表示逻辑关系（数组）。
- **链式存储**：地址可不连续，用**指针**表示逻辑关系（链表）。

**三、时间复杂度阶次（由小到大必背）**

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³)

指数阶：O(2ⁿ) < O(n!) < O(nⁿ)

## 9.2 线性结构：线性表、栈、队列、链表

**一、线性表**

- 非空表有唯一首结点、唯一尾结点。
- 除首结点外每个结点有唯一前驱；除尾结点外每个结点有唯一后继。
- **顺序表地址公式**：LOC(aᵢ) = LOC(a₁) + (i - 1) × L。

**二、栈（LIFO 后进先出）**

- 只在**栈顶（top）**插入和删除；栈底固定。
- 进栈：先存数据，top + 1；出栈：top - 1，再取数据。
- 应用：进制转换、括号匹配、**递归调用（递归工作栈）**。

**三、队列（FIFO 先进先出）**

- 队尾 rear 插入，队首 front 删除。
- **假溢出**：顺序队列头尾指针只增不减，尾指针到顶但前面有空位。
- **循环队列**：解决假溢出。
- 队空：front == rear。
- 队满：(rear + 1) % MAX == front（牺牲一个单元区分空满）。

**四、链表操作**

- **头插法**建表：生成顺序与输入顺序**相反**。
- **尾插法**建表：顺序一致。
- 单链表插入：`q->next = p->next; p->next = q;`
- 单链表删除：`q = p->next; p->next = q->next; free(q);`

> ⚠ 真题：两栈共享空间，栈 1 底在 V[1]，栈 2 底在 V[n]，**栈满条件 = top[1] + 1 == top[2]**（即 top[1] - top[2] == -1，等价 top[2] - top[1] == 1）。

## 9.3 数组与矩阵的压缩存储

**一、二维数组地址**（n 列、m 行，每元素占 L 个单元）

- **行优先**（C / Pascal）：LOC(aᵢⱼ) = LOC(a₁₁) + [(i - 1) × n + (j - 1)] × L。
- **列优先**（Fortran）：LOC(aᵢⱼ) = LOC(a₁₁) + [(j - 1) × m + (i - 1)] × L。

**二、特殊矩阵**

| 矩阵 | 压缩存储元素数 |
|---|---|
| 对称矩阵（下三角） | n(n+1)/2 个 |
| 三角矩阵 | n(n+1)/2 个 + 1（常数 c） |
| 三对角矩阵 | 3n - 2 个 |

三对角矩阵非零元素满足 |i - j| ≤ 1。

**三、稀疏矩阵**

- 非零元素少且分布无规律。
- 用**三元组 (i, j, aᵢⱼ)** 存储。

## 9.4 树与二叉树

**一、基本概念**

- 结点的度：子树个数；树的度 = 最大结点度。
- 叶子：度为 0 的结点。
- 树的深度（高度）：最大层次。

**重要公式（必背）**：n 个结点，所有分支结点度为 k，叶子数 n₀ = (n(k - 1) + 1) / k。

**二、二叉树 5 大性质**

| 性质 | 公式 |
|---|---|
| 第 i 层最多结点 | 2^(i-1) |
| 深度 k 最多结点 | 2^k - 1 |
| 叶子与度为 2 结点关系 | n₀ = n₂ + 1 |
| n 个结点完全二叉树深度 | ⌊log₂n⌋ + 1 |
| 编号 i 的结点 | 双亲 ⌊i/2⌋；左孩子 2i；右孩子 2i + 1 |

**三、满二叉树 vs 完全二叉树**

- **满二叉树**：每层都满，所有分支结点都有左右孩子。
- **完全二叉树**：除最后一层外都满，最后一层结点**从左到右连续**。

**四、二叉树遍历**

| 遍历 | 顺序 |
|---|---|
| 先序 DLR | 根 → 左 → 右 |
| 中序 LDR | 左 → 根 → 右 |
| 后序 LRD | 左 → 右 → 根 |
| 层序 | 从上到下，从左到右 |

- 由**先序 + 中序**可唯一确定二叉树。
- 由**后序 + 中序**可唯一确定二叉树。
- **先序 + 后序不能**唯一确定。

> ⚠ 真题：k 个结点的二叉链表，必有 **k + 1** 个空指针域。

**五、Huffman 树（最优二叉树）**

- WPL = Σ(wᵢ × lᵢ)（所有叶子带权路径长度之和）。
- 构造：每次选**两个权值最小**的树合并，根权值 = 两子树之和。
- Huffman 树**没有度为 1 的结点**。
- n 个叶子的 Huffman 树总结点数 = **2n - 1**。
- **Huffman 编码**：左分支 0，右分支 1；是**前缀编码**（任一字符编码不是另一字符编码的前缀）。

**六、树 / 森林与二叉树转换**

- 树 → 二叉树：**左孩子右兄弟**。
- 森林 → 二叉树：第一棵树的根是根，第一棵树的子树是左子树，**其余是右子树**。
- 三棵树结点数 n₁、n₂、n₃ → 二叉树右子树结点数 = n₂ + n₃。

## 9.5 图

**一、基本概念**

- 完全无向图边数：n(n - 1) / 2。
- 完全有向图弧数：n(n - 1)。
- 路径上边数 = 路径长度。
- 简单路径：顶点不重复。
- 回路（环）：第一个顶点 = 最后一个顶点。

**二、存储结构**

| 存储 | 特点 |
|---|---|
| 邻接矩阵 | n 个顶点用 n × n 矩阵；无向图对称；有向图第 i 行 = 出度，第 i 列 = 入度 |
| 邻接表 | 每个顶点一个链表；无向表不唯一；有向表有正 / 逆邻接表 |

**三、遍历**

- **DFS 深度优先**：类似树先序，用**栈**；时间 O(n + e)。
- **BFS 广度优先**：类似树层序，用**队列**；时间 O(n + e)。

**四、生成树**

- n 个顶点的连通图生成树有 **n - 1** 条边。
- DFS 得深度优先生成树；BFS 得广度优先生成树。

**五、最小生成树**

| 算法 | 思想 | 适用 |
|---|---|---|
| Prim 普里姆 | 从一个顶点出发，每次选连接集合内外**权值最小**的边 | 边稠密 |
| Kruskal 克鲁斯卡尔 | 把所有边按权排序，依次选不构成回路的边，选 n - 1 条 | 边稀疏 |

**六、拓扑排序（AOV 网）**

- AOV 网：顶点表示活动，边表示活动间优先关系。
- 算法：选**无前驱（入度为 0）**的顶点输出 → 删去该顶点和它的出边 → 重复。
- 若输出全部顶点 → 无环；若还有顶点没输出 → **有环**。

**七、最短路径**

- **Dijkstra 迪杰斯特拉**：按路径长度递增次序，求**单源点**到其他各点最短路径。
- **不能处理负权边**。

## 9.6 查找

**一、静态查找 / 树型查找结构**

| 结构 | 特点 |
|---|---|
| 二叉排序树 BST | 左子树 < 根 < 右子树；中序遍历得递增序列 |
| 平衡二叉树 AVL | 任意结点左右子树高度差 ≤ 1；平衡因子 ∈ {-1, 0, 1} |
| m 阶 B_树 | 多路平衡；根至少 2 棵子树；非叶至少 ⌈m/2⌉ 棵；**所有叶子在同一层** |
| B+ 树 | 叶子结点含全部关键字并**顺序链接**；非叶是索引 |

- 折半查找判定树是一棵**平衡二叉树**。

> ⚠ B_树叶子不链接成有序链表（那是 B+ 树）。

**二、哈希查找（散列）**

- 哈希函数：addr = H(key)。
- **冲突**：不同关键字映射到同一地址。
- **同义词**：H 函数值相同的不同关键字。
- 常用哈希函数：直接定址法、数字分析法、平方取中法、折叠法、**除留余数法** H(key) = key mod p（p 选素数）。

**冲突处理 4 法**

| 方法 | 说明 |
|---|---|
| 线性探测 | Hᵢ = (H(key) + i) mod m；易产生**聚集** |
| 二次探测 | Hᵢ = ±i² mod m |
| 链地址法 | 同义词链成链表；易删除，不易聚集 |
| 再哈希法 | 换一个哈希函数再算 |

## 9.7 排序

**一、排序算法对比总表**

| 算法 | 最好 | 最坏 | 平均 | 空间 | 稳定性 |
|---|---|---|---|---|---|
| 直接插入 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 希尔 | —— | —— | O(n^1.3) | O(1) | 不稳定 |
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 简单选择 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 快速排序 | O(n log n) | **O(n²)** | O(n log n) | O(log n) | 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | **O(n)** | 稳定 |
| 基数排序 | O(d(n + r)) | 同左 | 同左 | O(r) | 稳定 |

**二、记忆口诀**

- **稳定**：“**插冒归基**”（直接插入、冒泡、归并、基数）。
- **不稳定**：“**希快选堆**”（希尔、快速、简单选择、堆）。

**三、关键点**

- 快速排序最坏 O(n²)：当序列**正序或逆序**时。
- 归并排序辅助空间最大：O(n)。
- **堆排序**：
  - **大根堆**：根是最大值，用于**升序**排序。
  - **小根堆**：根是最小值，用于降序。
  - 堆是完全二叉树，但**完全二叉树不一定是堆**。
- **基数排序**：不比较关键字，按位分配收集，**适合位数少且基数小**的关键字。
