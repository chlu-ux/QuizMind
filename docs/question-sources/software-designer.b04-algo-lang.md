# 软件设计师（中级）考点精讲（算法设计与程序设计语言）

## 4.1 递归与分治策略

递归是函数直接或间接调用自身，必须有递归出口（终止条件）和递归调用两部分，递归调用使用栈保存调用现场，深度过大可能栈溢出。分治法把规模为 n 的问题分解成若干个规模较小、相互独立且与原问题相同的子问题，递归求解子问题后再合并子问题的解。适合分治的问题具有可分解、子问题相互独立、可合并的特点。典型的分治算法有归并排序、快速排序、二分查找、大整数乘法、棋盘覆盖和 Strassen 矩阵乘法。分治算法的时间复杂度常用递归式 T(n) = aT(n/b) + f(n) 分析：归并排序 T(n) = 2T(n/2) + O(n)，复杂度 O(n log n)；二分查找 T(n) = T(n/2) + O(1)，复杂度 O(log n)。汉诺塔问题移动 n 个盘子需要 2 的 n 次方减 1 次移动。

## 4.2 动态规划

动态规划适用于具有最优子结构和重叠子问题性质的问题。最优子结构是指问题的最优解包含子问题的最优解；重叠子问题是指递归求解时同一子问题被多次计算，动态规划用表格保存子问题的解，避免重复计算。动态规划的设计步骤是：刻画最优解的结构，递归定义最优解的值，自底向上计算最优解的值，构造最优解。典型问题有 0-1 背包、最长公共子序列（LCS）、矩阵链乘法、最长递增子序列和最短路径（Floyd）。0-1 背包问题中每件物品要么放入要么不放，用 dp[i][w] 表示前 i 件物品在容量 w 下的最大价值，时间复杂度为 O(nW)。最长公共子序列的递推式为：若 x[i] 等于 y[j] 则 c[i][j] = c[i-1][j-1] + 1，否则 c[i][j] 取 c[i-1][j] 与 c[i][j-1] 的较大者。动态规划与分治的区别在于，分治的子问题相互独立，动态规划的子问题相互重叠。

## 4.3 贪心算法

贪心算法在每一步都做出当前看来最好的选择，希望通过局部最优得到全局最优。贪心算法适用的问题要具有贪心选择性质和最优子结构：贪心选择性质是指全局最优解可以通过一系列局部最优选择得到。贪心算法不回溯，效率高，但不一定得到全局最优解。典型的贪心问题有活动选择问题（按结束时间最早优先）、部分背包问题（按单位重量价值从大到小装入）、哈夫曼编码、Prim 和 Kruskal 最小生成树、Dijkstra 单源最短路径。0-1 背包问题不能用贪心法求得最优解，必须用动态规划；而部分（分数）背包问题可以用贪心法求得最优解。

## 4.4 回溯法与分支限界法

回溯法按深度优先策略搜索解空间树，在搜索过程中用约束函数剪去不满足约束的分支，当某结点不可能包含可行解时就回溯到上一结点，适合求解组合问题、排列问题等需要找出所有解或可行解的问题。典型问题有 n 皇后问题、图的着色、0-1 背包、哈密顿回路和子集和问题。分支限界法按广度优先或最小耗费优先策略搜索解空间树，用限界函数剪去不可能产生最优解的分支，通常用于求最优解，常用队列式或优先队列式分支限界。回溯法一般找出所有满足约束条件的解，分支限界法一般找出满足约束条件的一个解或在某种意义下的最优解。典型的分支限界问题有 0-1 背包、旅行商问题和任务分配问题。

## 4.5 程序设计语言基础：分类、编译与解释

程序设计语言按抽象程度分为机器语言、汇编语言和高级语言。机器语言是 CPU 能直接执行的二进制指令，汇编语言用助记符表示指令，需要汇编程序翻译成机器语言。高级语言需要通过编译或解释才能执行：编译程序把源程序整体翻译成目标程序后再运行，运行速度快，但每次修改需重新编译；解释程序逐条翻译源程序语句并立即执行，不生成目标程序，便于调试和跨平台，但运行速度较慢。Java 先编译成字节码，再由 Java 虚拟机解释执行或即时编译。按编程范式，语言可分为过程式（C、Pascal）、面向对象（Java、C++）、函数式（Lisp、Haskell）和逻辑式（Prolog）等。预处理程序对源程序进行宏展开和文件包含等处理。

## 4.6 编译过程各阶段

编译程序的工作过程分为词法分析、语法分析、语义分析、中间代码生成、代码优化和目标代码生成六个阶段，同时伴随符号表管理和出错处理。词法分析读入源程序字符流，识别出单词，如关键字、标识符、常数和运算符，通常用有限自动机实现，发现的错误有非法字符等。语法分析根据文法检查单词序列是否符合语法规则，并构造语法树，常见错误有括号不匹配、缺少分号。语义分析检查程序的语义是否正确，如类型是否匹配、变量是否先声明后使用，不属于语法分析的范围。中间代码常见形式有三地址码、四元式和后缀式，与具体机器无关。代码优化对中间代码进行改进以提高运行效率，如常量折叠、公共子表达式消除、循环不变式外提。符号表在编译的各阶段保存和查询标识符的名字、类型、地址等信息。

## 4.7 形式语言：正规式、有限自动机与文法

文法由非终结符集合、终结符集合、产生式集合和开始符号四部分构成。乔姆斯基把文法分为四类：0 型（短语结构文法）、1 型（上下文有关文法）、2 型（上下文无关文法）和 3 型（正规文法）。程序设计语言的语法通常用上下文无关文法描述，词法用正规文法或正规式描述。正规式的运算有连接、选择和闭包，a* 表示 a 重复零次或多次，a+ 表示 a 重复一次或多次。有限自动机分为确定的有限自动机（DFA）和不确定的有限自动机（NFA），二者表达能力相同，DFA 在每个状态对每个输入符号有唯一的转移，NFA 可以有多个转移或空转移。正规式、正规文法和有限自动机三者表达能力等价。推导是从开始符号出发，用产生式逐步替换得到句子的过程；最左推导每次替换最左边的非终结符，最右推导每次替换最右边的非终结符。若一个句子有两棵不同的语法树，则该文法是二义性的。

## 4.8 表达式：前缀、中缀、后缀与三地址码

表达式有三种表示法：中缀表示法运算符在两个操作数之间，前缀表示法运算符在两个操作数之前，后缀表示法运算符在两个操作数之后。后缀表达式不需要括号，可以用栈计算，从左到右扫描，遇到操作数入栈，遇到运算符取出栈顶的两个操作数运算后把结果压回栈。表达式也可以用二叉树表示，对表达式树做前序遍历得到前缀表达式，中序遍历得到中缀表达式，后序遍历得到后缀表达式。三地址码的每条指令最多有三个地址，形如 x = y op z，例如 a = b + c * d 可以翻译为 t1 = c * d、t2 = b + t1、a = t2。四元式的形式是运算符、操作数 1、操作数 2 和结果四项。

## 4.9 参数传递、作用域与运行时存储分配

函数调用时参数传递方式主要有传值和传引用（传地址）。传值调用把实参的值复制给形参，形参的改变不会影响实参；传引用调用把实参的地址传给形参，形参的改变会直接影响实参。数组名作为参数传递的是首地址，属于传地址。变量的作用域是变量可以被访问的程序范围，局部变量只在函数内部有效，全局变量在整个程序中有效。程序运行时的内存区域通常分为代码区、静态数据区、栈区和堆区：静态区存放全局变量和静态变量，栈区存放局部变量、函数参数和返回地址，随函数调用自动分配和释放，堆区由程序员动态申请和释放，如 C 的 malloc 和 free、C++ 的 new 和 delete，若忘记释放会造成内存泄漏。递归调用依靠栈区保存每一层的现场。

## 4.10 数据类型、类型检查与常用语言要点

数据类型规定了数据的取值范围和可进行的运算。类型检查分为静态类型检查（编译时检查）和动态类型检查（运行时检查），C、C++、Java 是静态类型语言，Python、JavaScript 是动态类型语言。强类型语言不允许隐式的不安全类型转换。C 语言中，指针变量存放的是地址，取地址运算符用于获得变量地址，间接引用运算符用于取指针所指的内容；数组下标从 0 开始，字符串以空字符结束。C++ 在 C 的基础上增加了类、继承、多态和模板等面向对象特性，支持多继承。Java 是纯面向对象语言，只支持类的单继承，但一个类可以实现多个接口，由虚拟机自动进行垃圾回收。Java 的 int 类型固定为 4 字节，与平台无关。
