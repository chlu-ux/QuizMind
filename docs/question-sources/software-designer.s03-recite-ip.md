# 软件设计师（中级）基础知识速记（软件产权基础知识）

## 3.1 知识产权的基本概念

**一、知识产权是什么**

- 定义：人们基于**智力活动创造的成果**和**经营管理活动中的经验、知识**依法享有的权利。
- 《民法通则》：民事权利主体（公民、法人）基于**创造性的智力成果**享有的权利。

**二、知识产权的两大分类**

| 大类 | 包含 | 内容 |
|---|---|---|
| 著作权（版权） | 本身 | 作者对作品享有的**人身权 + 财产权** |
| 工业产权（产业产权） | **专利权 + 商标权** | 工业、商业、农业、林业等产业中具有实用经济意义的无形财产权 |

著作权中的**人身权**包括：发表权、署名权、修改权、保护作品完整权。

**三、知识产权的 4 大特点**

| 特点 | 含义 |
|---|---|
| 无体性 | 对象没有具体形体，是智力成果，是抽象财富 |
| 专有性 | 未经权利人许可，任何人不得使用，否则侵权 |
| 地域性 | 只在授予 / 确认其权利的国家受保护，出了该国不保护 |
| 时间性 | 只在法定期限内保护，过期进入公有领域，全人类共用 |

## 3.2 软件著作权

**一、软件的构成**：软件 = 计算机程序 + 有关文档。

- 计算机程序：代码化指令序列，包括**源程序和目标程序**。
- 文档：程序设计说明书、流程图、用户手册等。

> ⚠ 同一程序的源程序和目标程序是**同一作品**。

**二、相关主体**

- **软件开发者**：实际组织开发、直接开发并对软件承担责任的法人 / 组织，或独立完成并承担责任的自然人。
- **软件著作权人**：依法对软件享有著作权的自然人、法人或组织。

> 📌 中国公民 / 法人 / 组织开发的软件，**不论是否发表**，依法享有著作权（**自动取得**）。

**三、软件著作权人享有的 9 项权利**

| 权利 | 含义关键词 |
|---|---|
| 发表权 | 决定是否公之于众 |
| 署名权 | 表明开发者身份 |
| 修改权 | 增补、删节、改变指令 / 语句顺序 |
| 复制权 | 制作一份或多份 |
| 发行权 | 出售或赠与方式向公众提供原件 / 复制件 |
| 出租权 | **有偿**许可他人**临时**使用（软件不是出租主要标的除外） |
| 信息网络传播权 | 有线 / 无线方式提供，使公众在自选时间、地点获得 |
| 翻译权 | 将软件从**一种**自然语言文字转换成**另一种**自然语言文字 |
| （其他） | 许可他人使用并获报酬；全部或部分转让并获报酬 |

## 3.3 商业秘密、专利与商标

**一、商业秘密权**

- 定义（《反不正当竞争法》）：不为公众所知悉、能为权利人带来经济利益、具有实用性、经权利人采取保密措施的**技术信息和经营信息**。
- 性质：工业产权的一种。所有人必须采取合理保密措施使其不为公众所知悉。
- **3 个构成条件（必背）**：具有**经济价值**；具有**相对秘密性**（不为公众所知悉）；控制人采取了**合理的保密措施**。

**二、专利权**

- 定义：政府部门向发明人授予的在一定期限内**排他性**生产、销售或以其他方式使用发明的权利。
- 发明创造 = **发明 + 实用新型 + 外观设计**。

| 类型 | 保护对象 |
|---|---|
| 发明 | 对产品、方法或其改进提出的新的技术方案 |
| 实用新型 | 对产品的**形状、构造或其结合**提出的适于实用的新技术方案 |
| 外观设计 | 对产品的整体 / 局部的**形状、图案、色彩**结合作出的富有美感、适于工业应用的新设计 |

> ⚠ 实用新型只保护“形状 / 构造”，**不保护方法**。

**三、商标权**

- 注册商标：经**商标局**核准注册的商标，包括商品商标、服务商标、集体商标、证明商标。
- 商标权 = 商标专用权，注册人享有并受法律保护。
- **5 项权能**：排他使用权、收益权、处分权、续展权、禁止他人侵害权。
- 性质：无形资产，**可抵债（可转让）**。
- 转让规则：转让人和受让人**签订转让协议 + 共同向商标局提出申请**。

## 3.4 知识产权的保护期限

**一、软件著作权保护期**

| 主体 | 保护期 | 截止时间 |
|---|---|---|
| 自然人 | 终生 + 死后 **50 年** | 死亡后第 50 年的 12 月 31 日 |
| 合作开发 | 看**最后死亡者** | 最后死亡的自然人死亡后第 50 年的 12 月 31 日 |
| 法人 / 其他组织 | **50 年** | 软件**首次发表**后第 50 年的 12 月 31 日 |

- 起算点：软件著作权自**软件开发完成之日**起产生。
- **永久保护（不受限制）的 3 项权利**：✅ 署名权、✅ 修改权、✅ 保护作品完整权。

> ⚠ 法人特殊规则：软件自开发完成之日起 **50 年内未发表**的，不再保护。

**二、软件著作权的继承**

- 自然人死亡后（在保护期内）：继承人依《继承法》继承**除署名权以外**的其他权利。
- ⚠ **署名权是人身权，不能继承！**
- 法人 / 其他组织变更、终止后：有承受其权利义务的法人 → 由该法人享有；没有承受者 → **由国家享有**。

**三、四类知识产权保护期对比**

| 类型 | 保护期 | 起算点 | 可否续展 |
|---|---|---|---|
| 自然人软件著作权 | 终生 + 死后 50 年 | 开发完成日 | 不可 |
| 法人软件著作权 | 50 年 | 首次发表日 | 不可 |
| **发明专利** | **20 年** | **专利申请日** | 不可 |
| **实用新型专利** | **10 年** | **专利申请日** | 不可 |
| **外观设计专利** | **10 年** | **专利申请日** | 不可 |
| 公民作品发表权 | 终生 + 死后 50 年 | —— | 不可 |
| **商标权** | **10 年** | **核准注册日** | ✅ 可无限续展 |
| **商业秘密权** | 不确定（无期限） | —— | 只要保密就一直有 |

> 注：2021 年 6 月起，《专利法》把外观设计专利的保护期改为 15 年；本表按背诵资料写作 10 年，以考试所用版本为准。

**商标续展细节**

- 期满前 6 个月内申请续展。
- 每次续展有效期 10 年。
- 续展次数不限。
- 逾期不续展 → 商标权终止。

> 注：现行《商标法》规定在期满前 12 个月内办理续展，此期间未办的另有 6 个月宽展期；背诵资料沿用“6 个月”的说法。

## 3.5 软件著作权与专利权的归属

**一、软件著作权归属**

**① 一般原则**

- 归**软件开发者**。
- 如无相反证明，在软件上**署名**的自然人 / 法人 / 组织为开发者。

**② 合作开发**

- 有书面合同 → 按合同。
- 无合同或约定不明：
  - **可分割使用** → 开发者对各自开发部分**单独享有**著作权。
  - **不可分割使用** → **共同享有**，协商一致行使。
  - 协商不成又无正当理由 → 任何一方不得阻止他方行使**除转让权以外**的其他权利，但收益应**合理分配**。

**③ 委托开发**

- 有书面合同 → 按合同。
- 无合同或约定不明 → **归受托人**。

> ⚠ 注意：不是归委托人！

**④ 国家下达任务开发**

- 任务书 / 合同有规定 → 按规定。
- 未明确规定 → 归**接受任务的法人或其他组织**。

**⑤ 职务作品（自然人在单位任职期间开发）**

✅ 著作权**归单位**（单位可给自然人奖励）的 3 种情形：

- 针对本职工作中**明确指定的开发目标**开发。
- 开发的软件是从事本职工作活动所**预见的结果 / 自然结果**。
- **主要使用了单位的资金、专用设备、未公开的专门信息**等物质技术条件开发，并由单位承担责任。

**二、专利权归属**

**① 职务发明 vs 非职务发明**

| 类型 | 权利归属 | 专利权人 |
|---|---|---|
| 职务发明（执行本单位任务 或 主要利用本单位物质技术条件） | **单位** | 申请批准后**单位**为专利权人 |
| 非职务发明 | **发明人 / 设计人** | 申请批准后**发明人 / 设计人**为专利权人 |
| 利用本单位物质技术条件，单位与发明人订有合同约定 | **从其约定** | 约定优先 |

**② 合作完成 / 委托完成**

- 除另有协议外，申请专利的权利属于**完成或共同完成的单位 / 个人**。
- 申请被批准后，**申请的单位 / 个人**为专利权人。

**③ 同样发明创造的处理**

- **一发明一专利**：同样的发明创造只能授予一项专利权。
- 同日申请实用新型 + 发明：先获实用新型尚未终止 + 申请人**声明放弃**实用新型 → 可以授予发明专利权。
- **先申请原则**：两个以上申请人分别就同样发明创造申请 → 专利权授予**最先申请**的人。

## 3.6 商标权归属与侵权判断

**一、商标权归属**

- 取得方式：**注册取得**，向商标局申请。
- **恶意注册驳回**：不以使用为目的的恶意商标注册申请，应予驳回。
- **先申请 + 先使用原则**：两个以上申请人在**同一种 / 类似商品**上，以**相同或近似商标**申请：
  - 初步审定并公告**申请在先**的；
  - **同一天申请** → 初步审定并公告**使用在先**的，驳回其他人。
- **不得损害在先权利**：不得损害他人现有的在先权利，也不得以不正当手段**抢先注册**他人已经使用并有一定影响的商标。

**二、不知情下贩卖 / 使用侵权产品**

- 复制品持有人**不知道且没有合理理由应当知道**是侵权复制品 → **不承担赔偿责任**。
- 但应当**停止使用、销毁**该侵权复制品。
- 如果停止使用并销毁将给使用人造成**重大损失** → 可在向软件著作权人支付**合理费用**后继续使用。

**三、侵权例子**

- 甲公司买工具软件开发新软件，同时向客户提供工具软件复制品 → 侵犯著作权（未经许可复制分发）。
- 乙未注册商标就使用“恒友”，甲先使用并有一定影响，乙后来注册“恒友” → 侵犯商标权（抢注他人已使用并有一定影响的商标）。
