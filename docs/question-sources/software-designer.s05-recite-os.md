# 软件设计师（中级）基础知识速记（操作系统知识）

## 5.1 操作系统概述与分类

**一、OS 的定义与作用**

管理软硬件资源、控制程序执行、向用户提供友好接口。

两大作用：**资源管理提高效率 + 改善人机界面**。

**二、OS 4 大特征**：并发性、共享性、虚拟性、不确定性。

**三、OS 5 大功能**

| 功能 | 管理对象 |
|---|---|
| 进程管理 | 处理机**时间**（进程控制 / 同步 / 通信 / 调度） |
| 文件管理 | 文件空间、目录、读写、存取控制 |
| 存储管理 | 主存**空间**（分配回收、保护、地址映射、主存扩充） |
| 设备管理 | I/O 设备分配、启动、回收 |
| 作业管理 | 任务、界面、人机交互 |

**四、OS 分类**

- **批处理**：单道 / 多道，自动作业流。
- **分时**：时间片轮转，**多路性、独立性、交互性、及时性**。
- **实时**：要求**可靠性高**，响应快，交互性要求不高。
- **网络 OS**：共享网络资源（集中、C/S、P2P）。
- **分布式 OS**：各计算机无主次之分，可通信。

**嵌入式 OS 5 大特点**：① 微型化（资源少、功耗低）；② 可定制（可配置结构功能）；③ 实时性；④ 可靠性；⑤ 易移植性（硬件抽象层、板级支持包）。

## 5.2 进程状态与 PV 操作

**一、前趋图与程序执行**

- 前趋图：**有向无循环图**，箭头表示前趋关系（Pi → Pj 表示 Pi 完成后 Pj 才能开始）。
- 程序**顺序**执行三特征：顺序性、封闭性、可再现性。
- 程序**并发**执行：失去封闭性、不可再现性、间断性。

**二、进程组成与三态模型**

进程 = 程序段 + 数据段 + **PCB**（进程控制块）。

| 状态 | 含义 |
|---|---|
| 运行态 | 占有 CPU 正在执行 |
| 就绪态 | 除 CPU 外其他资源都有，一给 CPU 就能跑 |
| 阻塞态（等待态） | 等待某事件（如 I/O），即使给 CPU 也不能跑 |

**三态转换**

- 就绪 → 运行：调度程序选中。
- 运行 → 就绪：时间片到 / 有更高优先级进程抢占。
- 运行 → 阻塞：等待某事件（如 I/O 请求）。
- 阻塞 → 就绪：等待的事件发生（如 I/O 完成）。

> ⚠ **阻塞不能直接到运行；就绪不能直接到阻塞。**

**三、信号量与 PV 操作**

信号量 S：

- S ≥ 0：可用资源数。
- S < 0：|S| = 等待该资源的进程数。

**P 操作**（申请资源）：S = S - 1。

- S ≥ 0：继续执行。
- S < 0：阻塞自己，进等待队列。

**V 操作**（释放资源）：S = S + 1。

- S > 0：继续。
- S ≤ 0：唤醒一个等待进程，进入就绪队列。

**两类信号量**

- **公用信号量**（互斥）：初值 = 1 或资源数。
- **私用信号量**（同步）：初值 = 0 或某个正整数。

**互斥模板（临界区）**：P(S)（进入临界区）→ 临界区 → V(S)（出临界区）。

**同步经典例子（生产者 - 消费者，单缓冲区）**

- S1（空位数）初值 = 1；S2（满位数）初值 = 0。
- 生产者：生产 → P(S1) → 放产品 → V(S2)。
- 消费者：P(S2) → 取产品 → V(S1) → 消费。

> ⚠ 互斥信号量初值 = 1；同步信号量初值按资源数。售票系统互斥访问共享变量，S 初值 = 1。

## 5.3 进程调度、死锁与线程

**一、进程调度算法**

| 算法 | 规则 | 特点 |
|---|---|---|
| FCFS 先来先服务 | 按就绪先后顺序 | 公平，对短作业不利 |
| 时间片轮转 RR | 每个进程轮流用时间片 q | 公平，用于分时系统 |
| 优先级调度 | 优先级高的先跑 | 分抢占 / 非抢占 |
| 多级反馈队列 | 多个就绪队列，优先级高时间片短，跑不完降级 | 综合最优 |

- **可剥夺式（抢占）**：高优先级进程一来就抢 CPU。
- **不可剥夺式（非抢占）**：必须等当前进程主动释放。
- 时间片轮转**响应时间** t = n × q（n 个用户、q 时间片）。

**二、死锁**

**死锁 4 个必要条件**

- **互斥**：资源同一时刻只能一个进程使用。
- **请求与保持**：持有资源又申请新资源。
- **不可剥夺**：资源只能由持有者主动释放。
- **环路等待**：形成进程 - 资源的循环等待链。

**死锁处理策略**

| 策略 | 做法 |
|---|---|
| 预防 | 破坏 4 个必要条件之一 |
| 避免 | 运行时判断，**银行家算法** |
| 检测与解除 | 允许死锁发生，定期检测，剥夺资源 / 撤销进程 |

**死锁资源计算公式**：n 个进程，每个需要 R 个同类资源：

- 最多死锁数（所有进程都拿到 R-1 个）= n × (R - 1)。
- **不死锁最少资源数 = n × (R - 1) + 1**。

例：3 个进程，资源数 8，问 R 至少多大时可能死锁？不死锁需要 8 ≥ 3(R - 1) + 1，即 R ≤ 3。R = 3 时最多占用 3 × 2 = 6 < 8，不会死锁；R = 4 时最多占用 3 × 3 = 9 > 8，可能死锁 → 选 **4**。

**三、进程 vs 线程**

| 对比项 | 进程 | 线程 |
|---|---|---|
| 定义 | 资源分配的最小单位 | **CPU 调度 / 执行的最小单位** |
| 资源 | 独立拥有资源 | 共享所属进程的资源 |
| 切换开销 | 大 | 小 |
| 健壮性 | 一个进程崩溃不影响其他 | 一个线程崩溃可能导致整个进程崩溃 |
| 共享 | 进程间独立 | 同进程线程共享代码、数据、堆；**栈各自独立** |

## 5.4 存储管理：分页、分段与段页式

**一、分页存储管理**

- 把逻辑地址空间分成大小相等的**页**，主存分成相同大小的**块（页框）**。
- 逻辑地址 = **页号 P + 页内偏移 W**；通过**页表**实现页号 → 物理块号映射。
- 优点：无外部碎片；缺点：**有内部碎片**。

例：页大小 4KB = 2^12，所以页内地址占 12 位；逻辑地址 3C20H：页号 = 3C20H 右移 12 位 = 3，页内偏移 = C20H。

**二、分段存储管理**

- 按**逻辑模块**（主程序段、数据段、堆栈段）分段，段长不等。
- 逻辑地址 = **段号 + 段内地址**；段表记录**段始址 + 段长**。
- 优点：便于共享、保护；缺点：**有外部碎片**。

**三、段页式存储管理**

- 先分段，每段再分页。
- 逻辑地址 = **段号 + 段内页号 + 页内地址**。
- 系统中同时有**段表和页表**；段表项记录**页表始址和页表长度**。

## 5.5 设备管理与磁盘调度

**一、I/O 软件 4 层（由高到低）**

1. **用户层 I/O 软件**（库函数）。
2. **设备无关性软件**（系统调用、设备命名、保护、分配）。
3. **设备驱动程序**（直接控制硬件）。
4. **中断处理程序**（底层）。

I/O 软件**隐藏了 I/O 操作细节**，向用户提供统一接口。

**二、磁盘调度**

- 分两类：**移臂调度**（决定访问哪个柱面）+ **旋转调度**（决定访问哪个扇区）。
- 顺序：**先移臂，后旋转**。

**移臂调度算法对比**

| 算法 | 规则 | 特点 |
|---|---|---|
| FCFS | 按请求先后顺序 | 简单，可能来回跑 |
| SSTF 最短寻道优先 | 每次选离当前磁头最近的请求 | 可能产生“饥饿” |
| SCAN 电梯调度 | 沿当前方向走到头再折返 | 像电梯，不会饥饿 |
| C-SCAN 单向扫描 | 只沿一个方向走，到头后直接跳到另一端再单向走 | 更均匀 |

## 5.6 文件管理与空闲空间管理

**一、文件结构**

- 逻辑结构：**有结构**（记录式文件）；**无结构**（流式文件）。
- 物理结构（3 种）：

| 结构 | 特点 | 优缺点 |
|---|---|---|
| 连续（顺序）结构 | 文件占连续物理块 | 顺序访问快；有外部碎片，不宜动态增长 |
| 链接（串联）结构 | 块间用指针链接 | 适合顺序访问；随机访问慢，指针占空间 |
| 索引结构 | 为每个文件建索引表，记录逻辑块 → 物理块 | 随机访问快；索引表占空间 |

**二、文件目录**

- **FCB（文件控制块）**：描述文件的数据结构，至少包含**文件名 + 物理地址**；FCB 的集合 = 文件目录。
- 3 种目录结构：
  - **一级目录**：全系统一张表，不允许重名。
  - **二级目录**：主目录（用户名 → 用户目录指针）+ 用户目录，**允许不同用户文件重名**。
  - **多级目录（树型）**：绝对路径从根“/”开始，相对路径从当前目录开始。

**三、外存空闲空间管理 4 种方法**

1. **空闲区表**：适合连续文件。
2. **位示图（BitMap）**：每位对应一个物理块，0 空闲、1 占用。
3. **空闲块链**：所有空闲块链成链表。
4. **成组链接法**：分组管理空闲块（UNIX 用）。

**位示图计算（必背）**

- 磁盘总块数 = 磁盘容量 ÷ 块大小。
- 位示图大小（字数）= 总块数 ÷ 字长（位数 / 字）。

例：512GB / 4MB = 128K 块；字长 64 位 → 128K / 64 = **2048 字**。

- 物理块号 N：所在字 = N ÷ 字长（取商）；字内位 = N mod 字长。

例：2053 号块，字长 32 → 2053 ÷ 32 = 64 余 5，即第 64 字的第 5 位（字号、位号都从 0 起计）。
