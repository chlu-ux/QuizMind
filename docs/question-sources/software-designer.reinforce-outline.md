## 2. 怎么用

1. **先看讲义再刷题**：每个小节讲义不长，写的就是公式、速算步骤和易错点，可当速查表使用。
2. **按弱项刷**：R01 的计算题做错，回到对应小节看速算要点；R04 对应下午题的 5 道必做题（数据流图、数据库设计、UML、算法、设计模式）。
3. **计算题要自己动笔**：选项里的干扰项都是常见错误结果（漏加 1、单位没换算、公式用反），做错时看解析里的“陷阱”提示。

## 3. 速算公式速查表

以下公式均已在 R01 对应小节出过题，括号内是题目所在小节。

| 主题 | 公式 / 速算方法 | 例 |
|---|---|---|
| 补码范围（R1.1） | n 位补码 -2^(n-1) ~ 2^(n-1)-1；原码、反码 ±(2^(n-1)-1)；负数补码：从右往左第一个 1 及其右边不变，左边数值位取反 | 8 位补码 -128~127；-52 的补码 11001100 |
| 海明码（R1.3） | 校验位数 r 满足 2^r ≥ k + r + 1；校验位在 2 的幂位置 | k=8→4，k=16→5，k=32→6，k=64→7 |
| 码距（R1.3） | 检错 d-1 位，纠错 ⌊(d-1)/2⌋ 位 | d=5：检 4 位、纠 2 位 |
| CRC（R1.3） | 生成多项式最高次 r → 校验码 r 位；数据后补 r 个 0，模 2 除 | x^4+x+1 → 4 位校验码 |
| 流水线（R1.4） | T=(k+n-1)Δt；TP=n/T；S=nk/(k+n-1)；E=n/(k+n-1)；m 路超标量 T=(k+(n-m)/m)Δt | k=4，n=100：T=103Δt |
| CPU 性能（R1.5） | 时间=指令数×CPI÷主频；MIPS=主频(MHz)÷CPI；Amdahl：1÷((1-f)+f/r) | f=0.4，r=4 → 1.43 |
| 存储编址（R1.6） | 容量=末址-首址+1；n 根地址线寻址 2^n；芯片数=总容量÷单片容量（或字扩展×位扩展） | 4000H~5FFFH=8K |
| Cache（R1.7） | 平均访问时间=h×tc+(1-h)×tm；直接映射块号=主存块号 mod Cache 块数 | h=0.9，10ns/100ns → 19ns |
| 可靠性（R1.8） | 串联 ΠRi；并联 1-Π(1-Ri)；TMR=3R²-2R³；可用性=MTBF÷(MTBF+MTTR) | 0.9、0.8 串联 0.72，并联 0.98 |
| 磁盘与 RAID（R1.9） | 存取时间=寻道+旋转(30÷转速)+传输；RAID5=N-1，RAID6=N-2，RAID10=RAID1=N÷2 | 7200rpm 旋转延迟 4.17ms |
| 总线（R1.10） | 带宽=位宽÷8×频率÷每次传输周期数 | 32 位×100MHz=400MB/s |
| 死锁资源数（R1.11） | m ≥ n(w-1)+1 保证不死锁；信号量 S<0 时 |S| 为等待进程数 | n=3，w=4 → m≥10 |
| 调度（R1.12） | 周转=完成-到达；带权=周转÷服务；响应比=(等待+服务)÷服务 | — |
| 分页（R1.13） | 页号=地址÷页大小，偏移=地址 mod 页大小；EAT=(1-p)×内存+p×缺页处理 | 10000÷4096=2 余 1808 |
| 文件索引（R1.14） | 间接块地址数 n=块大小÷地址项；最大块数=直接+n+n²+…；位示图块号=字号×字长+位号 | — |
| 二叉树（R1.15） | n0=n2+1；完全二叉树 n 偶数 n0=n/2，奇数 n0=(n+1)/2；高度⌊log2 n⌋+1；哈夫曼 2n-1；二叉链表空指针 n+1 | n=1001 → n0=501 |
| 栈队列矩阵（R1.16） | 循环队列长度=(rear-front+m) mod m；对称矩阵下三角 i(i-1)/2+j；三对角 2i+j-2；出栈序列数=卡特兰数 | 出栈序列 n=4 → 14 |
| 查找与图（R1.17） | 折半最多 ⌊log2 n⌋+1；无向完全图 n(n-1)/2；有向完全图 n(n-1)；保证连通 (n-1)(n-2)/2+1 | n=1000 → 10 次 |
| 子网（R1.18） | /n 可用主机 2^(32-n)-2；块大小=256-掩码最后非 255 字节；聚合取最长公共前缀 | 192.168.0~3.0/24 → /22 |
| 网络性能（R1.19） | 奈奎斯特 2W·log2N；香农 W·log2(1+S/N)，30dB=1000；停等利用率=Tf÷(Tf+2Tp)；GBN 窗口 2^n-1，SR 窗口 2^(n-1) | 3kHz、30dB → 约 30kb/s |
| 多媒体（R1.20） | 图像=宽×高×位深÷8；音频=采样率×位数×声道×时间÷8；视频=每帧×帧率×时间 | 1024×768×24 位=2.25MB |
| 进度（R1.21） | 总时差=LF-EF；期望=(a+4m+b)÷6，标准差=(b-a)÷6；沟通路径 n(n-1)÷2 | a=6，m=9，b=18 → 10 |
| 测试度量（R1.22） | V(G)=E-N+2=判定数+1；边界值 4n+1 / 6n+1 / 5^n；MC/DC 至少 n+1；VAF=0.65+0.01ΣFi | E=11，N=9 → 4 |
| 数据库（R1.23） | R×S 元组相乘、属性相加；自然连接属性 a+b-公共；候选键先找入度为 0 的属性；关系模式数=实体数+m:n 联系数 | — |
