# 软件设计师（中级）考点精讲（下午案例分析基础）

## 14.1 数据流图：画法规则、平衡原则与常见错误

下午考试的数据流图题通常给出系统说明，要求补充缺失的外部实体、数据流或数据存储，并分析数据流图是否平衡。解题步骤：先从说明中找出所有外部实体，即系统之外的人、组织或其他系统；再找出系统的主要加工；然后确定数据存储，即需要保存的数据，如订单表、客户表；最后确定各元素之间的数据流并给出名称。数据流名称应是名词性短语，体现数据内容，如订单信息、库存信息；加工的名称应是动词短语，如处理订单、验证身份。加工与数据存储之间用数据流表示读写，写入数据存储的箭头指向存储，读取的箭头从存储指向加工。分层数据流图中，父图中某个加工的输入输出数据流必须出现在对应的子图中，即保持平衡；子图中若出现新的数据存储，只要它只被该子图内的加工使用，则不影响平衡，不必在父图中出现。补充缺失数据流时，要找出遗漏数据流的来源和去向，并为其命名。

## 14.2 数据库设计案例：E-R 图与关系模式

下午的数据库设计题通常要求补充 E-R 图中的实体、联系和联系类型，并完成关系模式，指出主键和外键。分析步骤：根据题目描述找出实体及其属性，确定每个实体的主键；分析实体之间的联系并确定联系类型，m:n 联系需要转换为独立的关系模式并包含联系自身的属性；转换为关系模式时，1:n 联系把 1 端的主键作为外键放入 n 端关系。关系模式的书写格式为关系名后跟括号内的属性列表，主键用下划线标出，外键用虚线或在说明中指出。例如员工关系的属性有员工号、姓名和部门号，其中部门号是外键，参照部门关系的主键部门号。题目中常见的联系类型判断方法是：一个部门有多名员工，每名员工只属于一个部门，则部门与员工是 1:n 联系；一名学生可以选修多门课程，一门课程可被多名学生选修，则学生与课程是 m:n 联系，对应选修关系的主键是学号与课程号的组合。关系模式还要判断是否满足 3NF，若存在传递依赖需要分解。

## 14.3 UML 案例：用例图、类图、状态图与顺序图读图要点

下午的 UML 题通常考查用例图、类图、状态图、活动图和顺序图。用例图题要求补充参与者和用例之间的关系：找参与者看谁与系统交互，找用例看参与者想通过系统完成什么目标；用例之间若某个用例必然调用另一个用例用包含关系，若是特定条件下才执行的可选行为用扩展关系。类图题要求补充类的属性、方法和类之间的关系及多重度：整体与部分生命周期一致用组合，生命周期独立用聚合，类的继承用泛化，类实现接口用实现；多重度要根据业务规则填写，如一个订单包含一个或多个订单项，订单一端为 1，订单项一端为 1..*。状态图题要求补充状态、事件和转换：每个状态的转换由事件触发，可带有条件和动作，初始状态只有出口，终止状态没有出口。顺序图题关注消息的先后顺序和参与对象，同步消息的发送者等待返回。

## 14.4 算法案例：C 语言基础与常考算法

下午的算法题常用 C 语言描述，考查分治、动态规划、贪心、回溯和分支限界等设计思想，要求填写缺失的代码、分析时间复杂度并指出所用的策略。常见题型：0-1 背包问题用动态规划，状态转移方程为 dp[i][w] = max(dp[i-1][w], dp[i-1][w-wi] + vi)，当物品放不下时 dp[i][w] = dp[i-1][w]；活动安排用贪心，按结束时间排序；n 皇后用回溯，约束是同行同列同对角线不能有两个皇后；快速排序和归并排序用分治；Prim 算法用贪心求最小生成树。C 语言基础：数组下标从 0 开始；二维数组按行存储；指针变量保存地址，通过解引用访问所指内容；函数参数默认按值传递，要在函数内修改实参需要传递指针；字符串以空字符结尾；用 malloc 申请的堆内存必须用 free 释放。分析题常要求写出算法的时间复杂度，嵌套循环的时间复杂度是各层循环次数之积，二分法每次把规模减半，复杂度为对数级。

## 14.5 设计模式案例：模式识别与 C++ / Java 实现要点

下午的设计模式题通常给出场景和类图，要求选出所用的模式并补全 C++ 或 Java 代码。识别模式的线索：需要保证全局只有一个实例，使用单例；创建对象时由子类决定具体类，使用工厂方法；创建一系列相关对象，使用抽象工厂；构造复杂对象的步骤固定，使用建造者；对已有接口进行转换，使用适配器；动态扩展功能，使用装饰器；为子系统提供统一入口，使用外观；控制对象访问，使用代理；对象状态变化需要通知多个对象，使用观察者；算法可以互换，使用策略；对象状态不同行为不同，使用状态；固定算法骨架而细节由子类实现，使用模板方法；对树形结构整体和部分一视同仁，使用组合；顺序访问集合元素，使用迭代器；需要撤销，使用命令或备忘录。代码补全要点：单例的构造函数为私有，并有静态获取实例的方法；Java 中接口用 interface、实现用 implements，继承用 extends；C++ 中纯虚函数声明抽象方法，抽象类至少含有一个纯虚函数，子类用 override 重写虚函数；装饰器和代理都持有被包装对象的引用并实现相同接口。
