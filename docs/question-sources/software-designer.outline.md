# 软件设计师（中级）考点大纲与出题计划

> 依据：全国计算机技术与软件专业技术资格（水平）考试「软件设计师」考试大纲的知识结构，结合历年真题的考查频率整理。
> 用途：作为题库生成的总纲——每个批次的讲义（`software-designer.bNN-*.md`）与题目（`software-designer.bNN-*.questions.json`）都按本表的章节编号展开。

## 1. 考试概况

| 科目 | 形式 | 题量与分值 | 本题库的覆盖方式 |
|---|---|---|---|
| 上午：基础知识 | 选择题，150 分钟 | 75 题 × 1 分 | 第 1–13 章，全部做成单选 / 判断题 |
| 下午：应用技术 | 案例分析，150 分钟 | 6 题，做 5 题（试题一至四必做：数据流图、数据库 E-R 设计、UML、算法；试题五、六二选一：C++ / Java 设计模式） | 第 14 章，把案例题背后的基础知识拆成选择 / 判断题 |

## 2. 出题原则

1. **围绕基础知识**：概念、定义、性质、公式、对比、典型计算。不出需要长篇推演的难题，也不出靠死记硬背偏门数字的题。
2. **重点多出**：重要度分三档，目标题数据此分配——
   - ★★★ 高频考点：每个小节 8–10 题；
   - ★★ 中频考点：每个小节 6–7 题；
   - ★ 低频考点：每个小节 4–5 题。
3. **题型**：单选（4 个选项）为主，判断为辅（约占 25%）。难度 1–5，基础概念为 1–2，典型计算与辨析为 3–4。
4. **每题都有出处**：`source_quote` 必须能在对应讲义小节里原样找到，服务端导入时会校验；讲义本身只写考点的基本事实，保证答案有据可查。
5. **选项顺序可变**：题库里的正确答案位置已打散；H5 刷题时每次进入题目还会再随机打乱选项（判断题的「正确 / 错误」保持固定），作答记录仍按原始选项序号保存。
6. **不与已有题重复**：已有 45 题（批次 0）覆盖的知识点，新批次换角度出题；服务端去重会拦下近似题。
