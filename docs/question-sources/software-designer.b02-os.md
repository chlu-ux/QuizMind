# 软件设计师（中级）考点精讲（操作系统）

## 2.1 操作系统概述：功能、分类与内核

操作系统是管理计算机硬件与软件资源的系统软件，主要功能包括处理机管理（进程管理）、存储管理、文件管理、设备管理和作业管理。按使用方式和功能，操作系统可分为批处理操作系统、分时操作系统、实时操作系统、网络操作系统、分布式操作系统和嵌入式操作系统。批处理系统追求系统吞吐量，分时系统强调交互性和及时响应，实时系统强调在规定时间内响应。微内核结构只把最基本的功能（进程通信、基本调度、内存管理等）放在内核中，其余服务运行在用户态，具有灵活、可扩展、可靠的优点，但消息传递带来额外开销。中断是指 CPU 暂停当前程序去处理突发事件的机制，分为外部中断（硬件中断）和内部中断（异常，如除零、缺页、系统调用）。用户程序通过系统调用请求操作系统服务，系统调用会使 CPU 从用户态转入内核态。

## 2.2 进程状态、PCB 与进程通信

进程是程序的一次执行过程，是系统进行资源分配的基本单位，由程序、数据和进程控制块（PCB）组成。PCB 是进程存在的唯一标志，保存进程标识、状态、优先级、程序计数器、寄存器和资源清单等信息。进程的五状态模型包括创建、就绪、运行、阻塞和终止。状态转换有：就绪到运行（进程被调度程序选中）、运行到就绪（时间片用完或被更高优先级进程抢占）、运行到阻塞（等待 I/O 或某事件）、阻塞到就绪（等待的事件发生）。阻塞状态不能直接转换为运行状态，就绪状态不能直接转换为阻塞状态。进程之间的通信方式有管道、消息队列、共享内存和信号量等，其中共享内存是最快的通信方式。线程是 CPU 调度的基本单位，同一进程的线程共享进程的资源，线程切换的开销比进程切换小。

## 2.3 进程同步与互斥：临界区与 PV 操作

进程间的制约关系有两种：互斥是指多个进程不能同时使用临界资源，同步是指进程之间需要按照一定的先后次序协调执行。临界资源是一次只允许一个进程使用的资源，每个进程中访问临界资源的那段代码称为临界区。进入临界区的原则是空闲让进、忙则等待、有限等待和让权等待。信号量是一个整型变量，只能通过 P 操作和 V 操作访问。P 操作使信号量减 1，若结果小于 0 则进程阻塞；V 操作使信号量加 1，若结果小于等于 0 则唤醒一个等待进程。互斥信号量的初值为 1，用 P(mutex) 和 V(mutex) 包住临界区；同步信号量的初值取决于资源的初始数量，如表示缓冲区空位数或产品数。当信号量值为负数时，其绝对值表示等待该信号量的进程数；当值为正数时，表示可用资源数。

## 2.4 前驱图与经典同步问题

生产者—消费者问题中，生产者生产产品放入缓冲区，消费者从缓冲区取走产品。通常设置三个信号量：互斥信号量 mutex 初值为 1，用于保护缓冲区；空位信号量 empty 初值为缓冲区大小 n；产品信号量 full 初值为 0。生产者执行 P(empty)、P(mutex)、放入产品、V(mutex)、V(full)；消费者执行 P(full)、P(mutex)、取出产品、V(mutex)、V(empty)。P 操作的顺序不能颠倒，若先 P(mutex) 再 P(empty)，缓冲区满时可能导致死锁。读者—写者问题允许多个读者同时读，但写者必须独占，读者与写者、写者与写者互斥。前驱图是一个有向无环图，用来表示进程之间的先后执行关系，若进程 P1 必须先于 P2 执行，则设置同步信号量 S12 初值为 0，P1 执行结束后 V(S12)，P2 开始前 P(S12)。

## 2.5 死锁的处理与资源数计算

死锁的处理方法有预防、避免、检测与解除三类。死锁预防通过破坏四个必要条件之一来实现：破坏互斥条件通常不可行；破坏占有并等待可采用资源一次性分配；破坏不可剥夺条件可采用资源剥夺；破坏循环等待可采用资源有序分配法，即按编号递增顺序申请资源。死锁避免允许进程动态申请资源，系统在分配前判断是否安全，银行家算法是典型方法。死锁检测与解除允许死锁发生，通过资源分配图化简检测死锁，再通过撤销进程或剥夺资源解除。死锁的资源数计算：设系统有 m 个同类资源，n 个进程，每个进程最多需要 w 个资源，则系统不会发生死锁的最小资源数为 n(w-1)+1，也就是当 m 大于等于 n(w-1)+1 时一定不会死锁。例如 3 个进程各需要 3 个资源，至少需要 7 个资源才能保证不发生死锁。

## 2.6 进程调度与作业调度算法

进程调度算法有先来先服务（FCFS）、短作业优先（SJF）、时间片轮转（RR）、优先级调度和多级反馈队列调度。先来先服务按到达顺序调度，对长作业有利，对短作业不利。短作业优先选择运行时间最短的作业，平均等待时间最短，但可能使长作业饥饿。时间片轮转按固定时间片轮流执行，适合分时系统，时间片太大会退化为先来先服务，太小则进程切换频繁、开销大。优先级调度按优先级高低选择进程，分为抢占式和非抢占式，低优先级进程可能饥饿，可通过老化技术缓解。多级反馈队列调度设置多个优先级不同、时间片不同的队列，新进程先进入最高优先级队列，用完时间片未结束则降到下一级队列。周转时间等于完成时间减去到达时间，带权周转时间等于周转时间除以运行时间。

## 2.7 分页存储管理与地址变换

页式存储管理把逻辑地址空间划分为大小相等的页，把物理内存划分为同样大小的页框（块），以页为单位分配内存，不要求连续。逻辑地址由页号和页内偏移两部分组成，页表记录每个页号对应的页框号。地址变换时，用页号查页表得到页框号，再与页内偏移拼接得到物理地址，即物理地址等于页框号乘以页大小再加页内偏移。页大小为 2 的整数次幂，例如页大小为 4KB 时，页内偏移占 12 位。为加快地址变换，在 CPU 中设置快表（TLB），保存最近使用的页表项，若快表命中则不必访问内存中的页表。页式存储管理只会产生页内碎片，不产生外部碎片，每个进程平均浪费半页。页式存储中，访问一个数据在没有快表的情况下需要两次访问内存：一次访问页表，一次访问数据。

## 2.8 分段、段页式存储与虚拟存储

段式存储管理按程序的逻辑结构把地址空间划分为若干长度不等的段，每段有自己的名字和长度，逻辑地址由段号和段内偏移组成，通过段表实现地址变换。段式存储便于信息共享和保护，不产生内部碎片，但会产生外部碎片。段页式存储管理先把程序分段，再把每段分成若干页，逻辑地址由段号、页号和页内偏移三部分组成，每次访问数据在没有快表时需要三次访问内存。虚拟存储技术利用程序的局部性原理，只把当前需要的部分装入内存，使得程序的逻辑地址空间可以大于物理内存。虚拟存储的特征有多次性、对换性和虚拟性。虚拟存储器的容量受地址位数和外存容量的限制。请求分页中，访问的页不在内存时产生缺页中断，由操作系统调入所缺页面。

## 2.9 页面置换算法的计算与抖动

页面置换算法在内存已满且发生缺页时选择被淘汰的页面。最佳置换算法（OPT）淘汰以后最长时间内不会再被访问的页面，缺页率最低但无法实现，常作为衡量其他算法的标准。先进先出算法（FIFO）淘汰最早调入内存的页面，实现简单，可能出现 Belady 异常。最近最久未使用算法（LRU）淘汰最长时间没有被访问的页面，性能接近 OPT，没有 Belady 异常。时钟算法（CLOCK）是 LRU 的近似，通过访问位和循环指针选择淘汰页面。例如页面访问序列为 1、2、3、4、1、2、5、1、2、3、4、5，分配 3 个页框时，FIFO 算法缺页 9 次，分配 4 个页框时缺页 10 次。抖动是指页面在内存和外存之间频繁调度，导致系统效率急剧下降，原因通常是分配给进程的页框数太少，可以通过工作集模型或降低多道程序度来缓解。工作集是进程在某段时间内实际访问的页面集合。

## 2.10 文件系统：文件结构、目录与存取

文件系统负责文件的存储、检索、共享和保护。文件的逻辑结构分为无结构的流式文件和有结构的记录式文件；物理结构有连续结构、链接结构和索引结构：连续结构支持随机存取和顺序存取，但易产生外部碎片、不便于文件动态增长；链接结构不产生外部碎片，便于增长，但只能顺序存取，指针占用空间；索引结构支持随机存取，需要额外的索引块。文件的存取方式有顺序存取和随机存取。目录结构有单级目录、两级目录和树形目录，树形目录允许重名文件在不同目录下存在，方便文件分类与共享。文件的路径分为绝对路径和相对路径，绝对路径从根目录开始，相对路径从当前目录开始。文件的访问控制常用访问控制表（ACL）或权限位来实现。

## 2.11 文件存储空间管理：位示图与索引节点

文件存储空间管理方法有空闲区表、空闲链表和位示图。位示图用一个二进制位表示磁盘或内存中一个物理块的使用情况，0 表示空闲，1 表示已占用。位示图的大小为物理块总数。已知位示图的字号 i、位号 j（均从 0 开始）和每个字的位数 w，则对应的物理块号为 i × w + j；反之，由块号 b 可求得字号为 b 除以 w 取整，位号为 b 除以 w 的余数。UNIX 的索引节点（i 节点）采用混合索引结构，包含若干直接地址项、一级间接、二级间接和三级间接地址项。设物理块大小为 B 字节，每个地址项占 4 字节，则一个一级间接索引块可以存放 B/4 个地址项。若有 10 个直接地址项，则文件大小不超过 10 个物理块时只需要直接地址，更大的文件需要用到间接地址项。文件越大，访问其末尾数据需要的磁盘访问次数越多。

## 2.12 设备管理：缓冲、SPOOLing 与 I/O 软件

设备管理的主要任务是提高设备利用率、方便用户使用。缓冲技术通过在内存中设置缓冲区来缓解 CPU 与外设之间速度不匹配的矛盾，减少对 CPU 的中断次数。常见的缓冲方式有单缓冲、双缓冲和缓冲池。SPOOLing（假脱机）技术利用磁盘作为缓冲，把独占设备改造成可共享的虚拟设备，典型应用是共享打印机，由输入井、输出井、输入缓冲区和输出缓冲区组成。设备按使用特性分为独占设备、共享设备和虚拟设备，打印机是典型的独占设备，磁盘是共享设备。I/O 软件分为四个层次，从下到上依次是中断处理程序、设备驱动程序、与设备无关的 I/O 软件和用户空间的 I/O 软件。设备驱动程序直接与硬件交互，是设备相关的。
