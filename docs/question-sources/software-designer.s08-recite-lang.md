# 软件设计师（中级）基础知识速记（程序设计语言基础知识）

## 8.1 程序设计语言概述

**一、低级 vs 高级**

- **低级语言**：机器语言（0 / 1 指令）、汇编语言。
- **高级语言**：Java、C、C++、Python 等，接近自然语言。

**二、编译 vs 解释**

| 对比项 | 编译 | 解释 |
|---|---|---|
| 过程 | **先翻译后执行**，生成独立目标程序 | **边翻译边执行**，不生成独立目标程序 |
| 效率 | **高** | 低 |
| 灵活性 | 较低 | 较高 |
| 可移植性 | **较差** | 较好 |

**三、语言分类**

| 类别 | 代表语言 |
|---|---|
| 命令式 / 结构化 | Fortran、Pascal、C |
| 面向对象 | C++、Java、Python、Smalltalk |
| 函数式 | LISP、Haskell、Scala、Scheme |
| 逻辑型 | PROLOG |

**四、程序设计语言 5 大基本成分**

1. 数据成分（数据类型）
2. 运算成分（算术、关系、逻辑、位运算）
3. 控制成分：顺序、选择、循环
4. 传输成分（赋值、输入输出）
5. 函数

**五、函数调用两种参数传递**

| 方式 | 特点 |
|---|---|
| 传值调用 Call by Value | 把实参值传给形参；形参变化**不影响**实参 |
| 传引用调用 Call by Reference | 形参是实参别名；对形参修改**直接改变**实参 |

## 8.2 编译程序 6 大阶段

| 阶段 | 任务 | 出错类型 |
|---|---|---|
| ① 词法分析 | 从左到右扫字符，识别**单词**（关键字、标识符、常数、运算符、分隔符） | 单词拼写错 |
| ② 语法分析 | 把单词串分解成语法单位（表达式、语句、程序），建**语法树**；检查结构合法性 | **括号不配对**等结构错误 |
| ③ 语义分析 | 类型检查、语义一致性；收集类型信息 | **类型不匹配、参数不匹配** |
| ④ 中间代码生成 | 生成与机器无关的中间代码 | —— |
| ⑤ 代码优化 | 改进中间代码，提高效率 | —— |
| ⑥ 目标代码生成 | 生成特定机器的目标代码 | 与机器密切相关 |

伴随全程：**符号表管理 + 出错处理**。

**错误分类**

- **静态错误（编译时发现）**：
  - 语法错误：单词拼写、括号不配对；
  - 静态语义错误：类型不匹配、运算符类型不合法。
- **动态错误（运行时发现）**：死循环、**变量为 0 作除数**、数组下标越界。

**前端 vs 后端**

- **前端**：词法 → 语法 → 语义 → 中间代码生成（**与机器无关**）。
- **后端**：代码优化 + 目标代码生成（**与机器有关**）。

## 8.3 中间代码形式

常用 4 种：

1. **后缀式（逆波兰式）**：运算符在操作数后，无括号，便于栈求值。
2. **四元式**：(OP, ARG1, ARG2, RESULT)，**编译器最常用**。
3. **三元式**：(OP, ARG1, ARG2)。
4. **树表示**：表达式树，叶子 = 操作数，非叶子 = 运算符。

**求后缀式方法（栈）**

- 操作数直接输出。
- 运算符：优先级 > 栈顶就压栈；≤ 栈顶就弹栈输出再压栈。
- 左括号直接压栈。
- 右括号：弹栈输出直到左括号。
- 结束：栈中运算符全部弹出。

例：9 + (3 - 1) × 3 + 10 ÷ 2 → `931-3×+102/+`

例：a * (b + c / d) - e → `abcd/+*e-`

## 8.4 文法和语言

**一、文法四元组** G = (VN, VT, P, S)

- VN：非终结符集合（大写字母）。
- VT：终结符集合（小写字母）。
- P：产生式集合。
- S：开始符号（属于 VN）。

**二、Chomsky 文法 4 分类**

| 类型 | 名称 | 对应语言 |
|---|---|---|
| 0 型 | 短语文法 | 图灵机 |
| 1 型 | 上下文有关文法 | 线性有界自动机 |
| 2 型 | **上下文无关文法** | 下推自动机 |
| 3 型 | **正规文法** | **有限自动机** |

**三、推导**

- **最左推导**：每次改写最左非终结符。
- **最右推导（规范推导）**：每次改写最右非终结符。
- 最右推导的逆过程 = **最左归约（规范归约）**。

**四、句型 vs 句子**

- **句型**：从 S 推导出的任意符号串（可含非终结符）。
- **句子**：只含终结符的句型。
- **语言**：所有句子的集合 L(G)。

**五、短语、直接短语、句柄（必考）**

- **短语**：语法树中任一子树叶子从左到右组成的串。
- **直接短语**：单层子树（不包含其他子树）的叶子串。
- **句柄**：**最左**直接短语。

## 8.5 词法分析与语法分析

**一、正规式**

- a|b：a 或 b。
- ab：ab 连接。
- a*：0 个或多个 a（含 ε）。
- (a|b)*abb：以 abb 结尾的 a / b 串。

**二、DFA vs NFA**

| 对比项 | DFA 确定有限自动机 | NFA 非确定有限自动机 |
|---|---|---|
| 后继状态 | **唯一** | 不唯一（可多个） |
| ε 弧 | 无 | 可有 |
| 状态转换函数 | f: S × Σ → S | f: S × Σ → 2^S |

- 二者等价：NFA 可用**子集法**化为 DFA。
- 终态集合 Z（用双圈表示）。

**三、语法分析两类方法**

| 方法 | 方向 | 代表算法 |
|---|---|---|
| 自顶向下 | 从 S 开始**最左推导**，试探匹配 | 递归下降分析、LL(1)、预测分析 |
| 自底向上 | 移进 - 归约，栈顶可归约串用产生式左部替代 | LR 分析、算符优先 |

> ⚠ 递归子程序法属于**自顶向下**。
