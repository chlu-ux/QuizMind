# 软件设计师（中级）考点精讲（数据结构）

## 3.1 数据结构基本概念与算法复杂度

数据结构研究数据的逻辑结构、存储结构和数据运算。逻辑结构分为线性结构（线性表、栈、队列、串）和非线性结构（树、图、集合）；存储结构有顺序存储、链式存储、索引存储和散列存储四种。算法是解决问题的有限步骤，具有有穷性、确定性、可行性、输入和输出五个特性。时间复杂度度量算法执行时间随问题规模 n 增长的趋势，常见量级按增长从慢到快为 O(1)、O(log n)、O(n)、O(n log n)、O(n²)、O(2^n)、O(n!)。空间复杂度度量算法执行所需的额外存储空间。单层循环执行 n 次的时间复杂度是 O(n)，双重循环各执行 n 次的时间复杂度是 O(n²)，循环变量每次翻倍或减半的循环时间复杂度是 O(log n)。

## 3.2 线性表：顺序表与链表

线性表是具有相同类型数据元素的有限序列，除首尾元素外每个元素有唯一前驱和唯一后继。顺序表用一组地址连续的存储单元存放元素，支持随机访问，按下标访问的时间复杂度为 O(1)，但插入和删除需要移动大量元素，平均移动次数约为 n/2，时间复杂度为 O(n)。链表用指针把结点链接起来，不要求存储空间连续，已知位置时插入和删除只需修改指针，时间复杂度为 O(1)，但不支持随机访问，按位查找需要 O(n)。单链表每个结点只有一个后继指针，只能向后遍历；循环链表的尾结点指针指向头结点；双向链表每个结点有前驱和后继两个指针，可以双向遍历，删除结点时不需要查找前驱。带头结点的链表使插入和删除的操作在首位置与其他位置保持一致。在顺序表的第 i 个位置插入元素，需要把第 i 个及以后的元素都后移一位。

## 3.3 栈与队列的应用

栈的出栈序列有限制：若入栈顺序为 1、2、3、……、n，则合法出栈序列的个数为卡特兰数，3 个元素有 5 种合法出栈序列。判断出栈序列是否合法的方法是：某元素出栈时，比它先入栈且尚未出栈的元素必须按入栈的逆序出栈。表达式求值利用栈：中缀表达式转后缀表达式时，运算数直接输出，运算符与栈顶比较优先级，栈顶优先级高于或等于当前运算符就弹出输出，左括号入栈，遇到右括号弹栈至左括号；后缀表达式求值时，遇到运算数入栈，遇到运算符弹出两个运算数计算后将结果入栈。栈还用于函数调用、递归和括号匹配。循环队列用数组实现，设数组长度为 m，队头指针 front、队尾指针 rear，则入队时 rear = (rear + 1) % m，出队时 front = (front + 1) % m，队列长度为 (rear - front + m) % m，若牺牲一个存储单元，则队满的条件是 (rear + 1) % m == front，队空的条件是 rear == front。

## 3.4 串与模式匹配（KMP）

串是由零个或多个字符组成的有限序列，长度为 0 的串称为空串，串中任意连续字符组成的子序列称为子串。模式匹配是在主串中查找模式串首次出现的位置。朴素的模式匹配算法（BF 算法）在失配时主串指针回溯，最坏时间复杂度为 O(n × m)。KMP 算法利用已经匹配的信息，主串指针不回溯，只移动模式串，时间复杂度为 O(n + m)。KMP 算法的核心是 next 数组：next[j] 表示模式串第 j 个字符之前的子串中，最长相等前后缀的长度加 1，下标从 1 开始时，next[1] = 0，next[2] = 1。例如模式串 abaab（下标从 1 开始）的 next 数组为 0、1、1、2、2。失配时模式串向右滑动到 next[j] 位置继续比较。

## 3.5 数组与矩阵的压缩存储

数组是相同类型元素的集合，二维数组可按行优先或列优先存放，行优先存放时 a[i][j]（下标从 0 开始，共 n 列）的地址为首地址加 (i × n + j) × 每个元素所占字节数。n 阶对称矩阵只需存放下三角（或上三角）元素，共 n(n+1)/2 个元素，按行优先存放下三角矩阵，元素 a[i][j]（i 大于等于 j，下标从 1 开始）对应的一维数组下标为 i(i-1)/2 + j。三角矩阵除了存放一个三角，还需要存放一个常数。稀疏矩阵的非零元素很少，常用三元组表（行号、列号、值）或十字链表存储，节省空间。对角矩阵等带状矩阵只需存放对角线附近的非零元素。

## 3.6 树与二叉树的性质

树是 n 个结点的有限集合，有且仅有一个根结点，其余结点分成若干互不相交的子树。结点的度是其子树个数，树的度是所有结点度的最大值，树的高度是结点的最大层数。度为 0 的结点称为叶子结点。树中结点数等于所有结点的度之和加 1。二叉树的性质：第 i 层最多有 2 的 i-1 次方个结点；高度为 h 的二叉树最多有 2 的 h 次方减 1 个结点；对任何二叉树，叶子结点数 n0 等于度为 2 的结点数 n2 加 1。满二叉树是每层都满的二叉树，完全二叉树是除最后一层外每层都满，且最后一层的结点都集中在左边。完全二叉树按层编号（从 1 开始）时，结点 i 的左孩子编号为 2i，右孩子编号为 2i+1，双亲编号为 i 除以 2 取整。具有 n 个结点的完全二叉树的高度为 log2(n) 向下取整加 1。

## 3.7 二叉树遍历的应用与线索二叉树

已知二叉树的前序序列和中序序列，或者中序序列和后序序列，可以唯一确定一棵二叉树；仅知道前序和后序序列则不能唯一确定。还原方法是：前序序列的第一个结点（或后序序列的最后一个结点）是根，在中序序列中找到根的位置，其左边是左子树的结点、右边是右子树的结点，然后递归处理。例如前序序列为 A B D E C F，中序序列为 D B E A C F，则根为 A，左子树含 D、B、E，右子树含 C、F，该二叉树的后序序列为 D E B F C A。线索二叉树利用二叉链表中的空指针域，使空的左指针指向该结点在某种遍历序列中的前驱，空的右指针指向后继，这样可以方便地找到前驱和后继。n 个结点的二叉链表共有 2n 个指针域，其中有 n-1 个指向孩子，空指针域有 n+1 个。

## 3.8 二叉排序树、平衡二叉树与 B 树

二叉排序树（BST）满足：左子树所有结点的值小于根，右子树所有结点的值大于根，左右子树也分别是二叉排序树，中序遍历得到递增序列。二叉排序树的查找效率与树形有关，平均查找长度为 O(log n)，最坏（退化成单链）为 O(n)。平衡二叉树（AVL 树）是任一结点的左右子树高度差（平衡因子）绝对值不超过 1 的二叉排序树，查找、插入和删除的时间复杂度都是 O(log n)。当插入导致失衡时通过旋转调整：LL 型失衡右旋，RR 型失衡左旋，LR 型先左旋再右旋，RL 型先右旋再左旋。B 树是多路平衡查找树，所有叶子结点在同一层，m 阶 B 树每个结点最多有 m 棵子树，常用于数据库和文件系统的索引。B+ 树的所有关键字都出现在叶子结点，叶子结点之间用指针链接，便于范围查询，非叶结点只起索引作用。

## 3.9 哈夫曼树与堆

哈夫曼树是带权路径长度（WPL）最小的二叉树。结点的带权路径长度是从根到该结点的路径长度乘以该结点的权值，树的 WPL 是所有叶子结点带权路径长度之和。构造方法：每次从森林中选出权值最小的两棵树合并成新树，新树根的权为两者之和，重复直到只剩一棵树。哈夫曼树中只有度为 0 和度为 2 的结点，n 个叶子结点的哈夫曼树共有 2n-1 个结点。哈夫曼编码是对每个字符按哈夫曼树的路径（左 0 右 1）得到的前缀编码，出现频率高的字符编码短，可以使总编码长度最短。前缀编码是指任何一个字符的编码都不是另一个字符编码的前缀。堆是完全二叉树，大顶堆的每个结点的值都不小于其左右孩子，小顶堆的每个结点的值都不大于其左右孩子，堆顶元素是最大值（大顶堆）或最小值（小顶堆）。

## 3.10 图的基本概念与存储结构

图由顶点集和边集组成，边有方向的称为有向图，没有方向的称为无向图。无向图中顶点的度是与它相关联的边数，边数等于所有顶点度数之和的一半；有向图中顶点的度分为入度和出度，所有顶点入度之和等于出度之和，等于边数。n 个顶点的无向完全图有 n(n-1)/2 条边，n 个顶点的有向完全图有 n(n-1) 条边。连通图是任意两个顶点之间都有路径的无向图，n 个顶点的连通图至少有 n-1 条边；强连通图是有向图中任意两个顶点之间都存在双向路径。图的存储方式有邻接矩阵和邻接表：邻接矩阵用二维数组表示顶点之间的关系，空间复杂度为 O(n²)，适合稠密图，无向图的邻接矩阵是对称矩阵；邻接表为每个顶点建立一个边链表，空间复杂度为 O(n + e)，适合稀疏图。

## 3.11 图的遍历与拓扑排序

图的遍历有深度优先搜索（DFS）和广度优先搜索（BFS）。深度优先搜索类似树的先序遍历，沿一条路径尽量深入，不能前进时回退，用栈（或递归）实现；广度优先搜索类似树的层次遍历，先访问起点的所有邻接点再访问下一层，用队列实现。使用邻接表存储时，两种遍历的时间复杂度都是 O(n + e)，使用邻接矩阵时是 O(n²)。拓扑排序针对有向无环图（DAG），把所有顶点排成一个线性序列，使得若存在从 u 到 v 的边，则 u 在 v 之前。拓扑排序的步骤是：反复选择入度为 0 的顶点输出，并删除它及其出边，直到所有顶点输出，或剩下的顶点入度都不为 0，说明图中存在环。拓扑序列可能不唯一。

## 3.12 最小生成树与最短路径

最小生成树是连通带权无向图中权值之和最小的生成树，n 个顶点的生成树有 n-1 条边。Prim 算法从某一顶点出发，每次选取连接已选顶点集合与未选顶点集合的权值最小的边加入，时间复杂度为 O(n²)，适合稠密图。Kruskal 算法按权值从小到大依次选择边，若加入后不形成回路就保留，直到选够 n-1 条边，时间复杂度为 O(e log e)，适合稀疏图。最短路径问题中，Dijkstra 算法求单源最短路径，每次选取当前距离源点最近的未确定顶点并更新其邻接点的距离，要求边的权值非负，时间复杂度为 O(n²)；Floyd 算法求每对顶点之间的最短路径，时间复杂度为 O(n³)，允许边权为负但不能有负权回路。

## 3.13 AOE 网与关键路径

AOE 网是用边表示活动、顶点表示事件的带权有向无环图，边上的权表示活动持续时间。AOE 网中从源点到汇点的路径长度最长的路径称为关键路径，关键路径的长度就是完成整个工程所需的最短时间。事件的最早发生时间是从源点到该顶点的最长路径长度。活动的最早开始时间等于其起点事件的最早发生时间；活动的最迟开始时间等于其终点事件的最迟发生时间减去活动持续时间；活动的松弛时间等于最迟开始时间减最早开始时间，松弛时间为 0 的活动是关键活动。关键活动延期会使整个工程延期，缩短关键活动的时间可以缩短工期，但关键路径可能不止一条。

## 3.14 查找：顺序、折半、分块与散列

顺序查找从头到尾逐个比较，适用于顺序表和链表，对有序无序都可用，平均查找长度为 (n+1)/2，时间复杂度为 O(n)。折半查找要求线性表有序且采用顺序存储，每次与中间元素比较并将范围缩小一半，时间复杂度为 O(log n)。分块查找把表分成若干块，块内无序、块间有序，先查索引表再查块内，效率介于顺序查找与折半查找之间。散列表通过散列函数把关键字映射到存储地址，查找时间复杂度理想情况下为 O(1)。常用散列函数有除留余数法 H(key) = key mod p，p 取不大于表长的最大质数。不同关键字映射到同一地址称为冲突，处理冲突的方法有开放定址法（线性探测、二次探测）和链地址法。装填因子等于表中记录数除以表长，装填因子越大，冲突越多。

## 3.15 排序（一）：插入、冒泡与选择排序

直接插入排序把待排元素插入前面已排序的序列，最好情况（已有序）时间复杂度为 O(n)，最坏和平均为 O(n²)，是稳定排序。折半插入排序减少比较次数，但移动次数不变。希尔排序是缩小增量的分组插入排序，时间复杂度与增量序列有关，是不稳定排序。冒泡排序每趟把相邻逆序元素交换，最好情况（已有序且带标志位）为 O(n)，最坏和平均为 O(n²)，是稳定排序，n 个元素最多进行 n-1 趟。简单选择排序每趟选出最小元素放到已排序序列末尾，比较次数固定为 n(n-1)/2，与初始序列无关，时间复杂度始终为 O(n²)，是不稳定排序。排序的稳定性是指值相同的元素在排序前后相对次序保持不变。内部排序是在内存中进行的排序，外部排序需要在内外存之间交换数据。

## 3.16 排序（二）：快速、堆、归并与基数排序

快速排序选取枢轴，把序列划分成小于和大于枢轴的两部分再递归排序，平均时间复杂度为 O(n log n)，平均空间复杂度为 O(log n)，最坏情况（序列已有序且枢轴取端点）为 O(n²)，是不稳定排序，在内部排序中平均性能最好。堆排序先建立大顶堆，再反复把堆顶与末尾元素交换并调整堆，时间复杂度始终为 O(n log n)，空间复杂度为 O(1)，是不稳定排序。归并排序把序列分成两半分别排序再合并，时间复杂度始终为 O(n log n)，需要 O(n) 的辅助空间，是稳定排序。基数排序按关键字的各位依次分配和收集，时间复杂度为 O(d(n + r))，是稳定排序，不基于比较。基于比较的排序算法，时间复杂度下界为 O(n log n)。
