# 软件设计师（中级）基础知识速记（算法分析与设计）

## 11.1 算法基本概念

**一、算法 5 大特性**

| 特性 | 含义 |
|---|---|
| 有穷性 | 必须在有限步后结束，每步在有限时间内完成 |
| 确定性 | 每条指令含义确切，**无二义性**，一个入口一个出口 |
| 可行性 | 操作可通过已实现的基本运算执行有限次完成 |
| 输入 | 零个或多个输入 |
| 输出 | 一个或多个输出（与输入有特定关系） |

> ⚠ 算法 ≠ 程序：程序是算法用某种语言的实现；算法必须可终止，所以**不是所有程序都是算法**（如操作系统死循环）。

**二、好算法 4 标准**：正确性、可读性、健壮性（容错）、通用性。

## 11.2 时间复杂度分析与主定理

**一、4 种方法**

| 方法 | 思路 |
|---|---|
| 展开法 | 把递归式右边不断代入展开，直到成求和式 |
| 代换法 | 先猜解的形式，再用数学归纳法证明 |
| 递归树法 | 画递归树，每层代价相加得总代价（适合给猜测） |
| 主方法（主定理） | 套公式，T(n) = aT(n/b) + f(n) |

**二、主定理 3 种情况**

设 T(n) = aT(n/b) + f(n)，记 c = log_b a：

| 情况 | 条件 | 结果 |
|---|---|---|
| ① | f(n) = O(n^(c-ε)) | T(n) = Θ(n^c) |
| ② | f(n) = Θ(n^c · lg^k n) | T(n) = Θ(n^c · lg^(k+1) n) |
| ③ | f(n) = Ω(n^(c+ε)) | T(n) = Θ(f(n)) |

> 注：背诵资料把表中的 Θ 印成了 O，这里按通行写法还原。

**典型例子**

- T(n) = 9T(n/3) + n → a = 9，b = 3，c = 2，f = n → 情况① → **O(n²)**。
- T(n) = T(2n/3) + 1 → a = 1，c = 0，f = 1 → 情况②（k = 0）→ **O(lg n)**。
- T(n) = 4T(n/2) + cn → a = 4，b = 2，c = 2，f = cn → 情况① → **O(n²)**。

## 11.3 分治法与归并排序

**一、设计思想**：把大问题分解成若干**独立的、与原问题相同的**子问题，递归求解再合并。

**二、三步骤**：分解 → 求解 → 合并。

**三、适用 4 条件**

1. 规模小到一定程度可直接解。
2. 可分解为规模更小的**相同**子问题（最优子结构）。
3. 子问题的解**可合并**为原问题的解。
4. 子问题**相互独立**（不含公共子问题）。

> ⚠ 第③条是关键；若子问题不独立（有重叠）→ 用**动态规划**。

**四、经典例子**：汉诺塔、二分查找、归并排序、快速排序、最大子段和。

**五、归并排序**

- 时间复杂度：O(n log n)（最好 / 最坏 / 平均都是）。
- 空间复杂度：O(n)（需辅助数组）。
- **稳定排序**（相同元素顺序不颠倒）。

**六、最大子段和（分治版）**

- 3 种情况：最大子段在左半、右半、**跨越中间**。
- 跨越中间 = 左半含末尾最大和 + 右半含开头最大和。
- 时间复杂度：O(n log n)。

## 11.4 动态规划

**一、核心思想**：把复杂问题分解成**相互重叠**的子问题，把子问题结果**存起来避免重复计算**。一般求最优解。

**二、3 个特征（必背）**

- **重叠子问题**（子问题不独立！与分治区别）。
- **最优子结构**（最优解包含子问题最优解）。
- **无后效性**（未来只与当前状态有关，与过去无关）。

> ⚠ 折半查找**没有重叠子问题**，所以不用 DP。

**三、4 步骤**

1. 分析是否满足最优性原理。
2. 分解问题，写出**递归方程**。
3. **自底向上**计算最优值。
4. （如需）根据记录构造最优解。

**四、经典例子**：0-1 背包、最长公共子序列（LCS）、矩阵连乘（矩阵链乘）。

**五、0-1 背包递归式**

F[i][j]：前 i 个物品、容量 j 的最大价值。

- 若 j < w[i]：F[i][j] = F[i-1][j]（放不下）。
- 若 j ≥ w[i]：F[i][j] = max(F[i-1][j], F[i-1][j-w[i]] + v[i])。

**六、矩阵连乘**：时间复杂度 O(n³)；空间复杂度 O(n²)。

**七、LCS**

- 蛮力法：O(n · 2ⁿ)（对 X 每个子序列判断）。
- DP 法：O(n²)。

## 11.5 贪心算法

**一、核心思想**：每一步都做**当前看来最好**的选择（局部最优），寄希望于局部最优推出全局最优。

**二、两个性质**

- **贪心选择性质**：整体最优可通过一系列局部最优选择达到（**贪心与 DP 的主要区别**）。
- **最优子结构**。

**三、经典例子**：最小生成树（Prim、Kruskal）、Dijkstra 单源最短路径、Huffman 编码、分数背包（可分割物品）、活动选择问题。

**四、关键对比**

| 问题 | 贪心是否最优 |
|---|---|
| 0-1 背包（物品不能分割） | ❌ 贪心不能保证最优 → 用 DP |
| 分数背包（物品可分割） | ✅ 贪心最优（按单位重量价值从大到小装） |

> ⚠ 找零钱反例：硬币 1、5、11，找 15，贪心给 11 + 1 × 4 = 5 个；最优是 5 × 3 = 3 个。所以贪心**不一定最优**。

**五、活动选择问题**：贪心策略：按**结束时间递增**排序，每次选与已选活动兼容且**结束最早**的活动，让剩余时间最多。

## 11.6 回溯法

**一、核心思想**：**深度优先搜索（DFS）解空间树，走到死路就回溯**（递归返回）换路。美称：“通用解题方法”。

**二、经典例子**：深度优先搜索、0-1 背包、正则匹配、八皇后（n 皇后）、数独、全排列。

**三、解空间相关概念**

- **状态空间树**：把解空间组织成树。
- **状态结点**：树上任意结点。
- **解状态结点**：叶子结点。
- **回答状态结点**：满足约束的叶子结点（对应一个解）。

**四、搜索方式**

- 求**所有解**：回溯到根，根的所有子树搜遍。
- 求**任一解**：搜到一个解就停。
- 求**最优解**：搜遍所有，保留最优。

**五、剪枝函数**

- **约束函数**：剪去不满足约束的子树。
- **目标函数**：剪去得不到最优解的子树（优化问题）。

**六、n 皇后判断**

- 不能同列。
- 不能同斜线：|行差| == |列差| 则同斜线。

## 11.7 分支限界法与五大策略对比

**一、核心思想**：**广度优先搜索（BFS）解空间树**，目标是找一个解或最优解。

**二、回溯 vs 分支限界（必考对比）**

| 对比项 | 回溯法 | 分支限界法 |
|---|---|---|
| 搜索方式 | **深度优先（DFS）** | **广度优先（BFS）** |
| 求解目标 | 找出**所有**满足约束的解 | 找出**一个解或最优解** |
| 活结点表 | 栈 | 队列 / 优先队列 |

**三、两种分支限界**

- **队列式（FIFO）**：活结点按先进先出扩展。
- **优先队列式**：按优先级（如目标函数值）扩展最优结点。

**四、五大策略对比总表**

| 策略 | 子问题关系 | 搜索方式 | 经典例子 |
|---|---|---|---|
| 分治法 | 子问题**独立** | 递归分解 | 归并排序、快排、二分查找 |
| 动态规划 | 子问题**重叠** | **自底向上填表** | 0-1 背包、LCS、矩阵连乘 |
| 贪心 | 局部最优 | 每步选最优 | 分数背包、Dijkstra、Huffman、活动选择 |
| 回溯 | 枚举所有解 | **深度优先 DFS** | n 皇后、0-1 背包、数独 |
| 分支限界 | 找最优解 | **广度优先 BFS** | 0-1 背包、旅行商 |
