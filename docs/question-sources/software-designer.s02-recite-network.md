# 软件设计师（中级）基础知识速记（网络与信息安全）

## 2.1 网络拓扑与 OSI 七层模型

**一、拓扑结构**

- **广域网**：树型、不规则型。
- **局域网**：**星型、环型、总线型**。

**二、OSI 七层模型**

| 层 | 名称 | 主要功能 | 典型设备 / 协议 |
|---|---|---|---|
| 7 | 应用层 | 为应用程序提供网络服务 | HTTP、FTP、SMTP、DNS |
| 6 | 表示层 | **压缩、加密、解密、格式转换** | JPEG、ASCII |
| 5 | 会话层 | 建立、管理、终止会话 | —— |
| 4 | 传输层 | 端到端可靠传输、流量控制 | TCP、UDP |
| 3 | 网络层 | 路由选择、分组转发 | IP、ARP、ICMP、路由器 |
| 2 | 数据链路层 | 成帧、差错校验、MAC 寻址 | 交换机、网桥、VLANtag |
| 1 | 物理层 | 比特流透明传输 | 中继器、集线器 |

**三、各层互连设备对比**

| 设备 | 工作层 | 功能 |
|---|---|---|
| 中继器、集线器 | 物理层 | 信号放大整形 |
| 网桥、交换机 | 数据链路层 | 根据 MAC 地址转发帧 |
| 路由器 | 网络层 | 根据 IP 地址路由转发 |
| 网关 | 高层（应用层） | 不同协议网络互连 |

## 2.2 局域网、以太网与广域网协议

**一、局域网（LAN）**

决定 LAN 特性的 3 要素：**传输介质、拓扑结构、介质访问控制方法**。

- **LLC 子层**：逻辑链路控制，提供面向连接 / 无连接服务。
- **MAC 子层**：介质访问控制、帧寻址。

**二、以太网 IEEE 802.3**

介质访问控制：**CSMA/CD**（载波监听多路访问 / 冲突检测）。

标准：

- 802.3：10Mbps，同轴电缆。
- 802.3u：快速以太网 100Mbps，双绞线。
- 802.3z：千兆以太网 1000Mbps，光纤 / 双绞线。

**三、广域网协议**

- **PPP**：点对点协议，用于拨号。
- **PPPoE**：以太网承载 PPP，ADSL 接入用。
- **帧中继（FR）**：帧为单位，统计复用。
- **ATM**：异步传输模式，固定长度**信元**。

## 2.3 TCP/IP 协议族

**一、TCP/IP 四层模型**

| TCP/IP 层 | 对应 OSI 层 | 主要协议 |
|---|---|---|
| 应用层 | 应用 + 表示 + 会话 | HTTP、FTP、SMTP、DNS、Telnet |
| 传输层 | 传输 | TCP、UDP |
| 网际层（IP 层） | 网络 | IP、ARP、RARP、ICMP |
| 网络接口层 | 物理 + 数据链路 | 以太网、令牌环 |

**二、网际层协议**

- **IP**：封装、分片、路由。
- **ARP**：IP 地址 → **MAC 地址**。
- **RARP**：MAC 地址 → **IP 地址**。
- **ICMP**：差错与控制报文（Ping 用它）。

**三、TCP vs UDP**

| 对比项 | TCP | UDP |
|---|---|---|
| 连接 | **面向连接** | 无连接 |
| 可靠性 | 可靠（确认重传） | 不可靠 |
| 速度 | 慢 | **快、开销小** |
| 流量 / 拥塞控制 | 有 | 无 |
| 用途 | 文件传输、邮件、网页 | 视频、语音、DNS |
| 端口号 | 16 位 | 16 位 |

> ⚠ 两者都用**端口**寻址（16 位端口号）。

**四、网关协议**

- **内部网关协议 IGP**（自治系统内部）：RIP、OSPF、IS-IS。
- **外部网关协议 EGP**（自治系统之间）：BGP、BGP4。

## 2.4 域名、IP 地址与 DNS

**一、域名**

- 格式：**主机名.本地名.组名.顶级域名**（从右往左级别升高）。
- 类别顶级域名：com（商业）、net（网络）、org（组织）、gov（政府）、edu（教育）、mil（军事）、int（国际组织）。
- 国家顶级域名：cn（中国）、uk（英国）、jp（日本）……

**二、IP 地址分类**

| 类别 | 首字节范围 | 首位特征 | 用途 |
|---|---|---|---|
| A 类 | 1 ~ 126 | 0 | 大型网络 |
| B 类 | 128 ~ 191 | 10 | 中型网络 |
| C 类 | 192 ~ 223 | 110 | 小型网络 |
| D 类 | 224 ~ 239 | 1110 | **组播（多播）** |
| E 类 | 240 ~ 255 | 1111 | 保留实验 |

- IPv4：**32 位**，点分十进制。
- IPv6：**128 位**，冒分十六进制；地址空间是 IPv4 的 2^96 倍。

**三、MAC 地址 vs IP 地址**

| 对比项 | MAC 地址 | IP 地址 |
|---|---|---|
| 性质 | **物理地址 / 硬件地址** | 逻辑地址 |
| 长度 | **48 位（6 字节）** | 32 位（IPv4） |
| 工作层 | 数据链路层 | 网络层 |
| 分配依据 | **制造商（OUI + 扩展 ID）** | 网络拓扑 |
| 可变性 | 出厂固定（理论上唯一） | 可改变 |
| 对应协议 | —— | ARP / RARP 互转 |

**四、DNS 域名解析**

- 作用：**域名 ↔ IP 地址**互转。
- 4 类域名服务器：**根域名服务器、顶级域名服务器（TLD）、本地域名服务器、主 / 辅助域名服务器**。
- 解析过程：本地查缓存 → 本地域名服务器 → 根 → 顶级 → 权威 → 返回并缓存。

常用命令：

- nslookup：可测正 / 反向解析。
- ping、tracert：只能测正向。
- ipconfig /flushdns：**清 DNS 缓存**。
- ipconfig /displaydns：显示 DNS 缓存。
- ipconfig /release：释放 IP。
- ipconfig /renew：更新 IP。

## 2.5 应用层协议、电子邮件与 WWW

**一、常见应用层协议**

| 协议 | 传输层 | 端口 | 用途 |
|---|---|---|---|
| FTP | TCP | **20（数据）、21（控制）** | 文件传输 |
| SSH | TCP | 22 | 安全远程登录 |
| Telnet | TCP | **23** | 远程登录（明文） |
| SMTP | TCP | **25** | 发送邮件 |
| DNS | UDP | **53** | 域名解析 |
| DHCP | UDP | 67（服务器）、68（客户机） | 自动分配 IP |
| HTTP | TCP | **80** | 网页 |
| POP3 | TCP | **110** | 收邮件（下载后删除） |
| HTTPS | TCP | **443** | 加密网页 |
| SNMP | UDP | 161 | 网络管理 |
| TFTP | UDP | 69 | 简单文件传输 |

**二、电子邮件协议**

- **SMTP**：发送邮件（推协议）。
- **POP3**：接收邮件（下载后服务器删除）。
- **IMAP4**：接收邮件（邮件留在服务器，可在线操作）。
- **MIME**：扩展邮件，支持**多媒体附件**、非 ASCII。

**三、WWW 服务**

- 协议：**HTTP**（超文本传输协议，默认 80）。
- 页面描述：**HTML**。
- 定位：**URL**，格式：协议://主机名:端口/路径。
- HTTP 请求过程：输入 URL → DNS 解析 → 建立 TCP 连接 → 发请求 → 服务器响应 → 断开 TCP → 浏览器解析显示。

## 2.6 网络攻击与加密算法

**一、网络攻击分类**

| 类型 | 特点 | 例子 |
|---|---|---|
| 被动攻击 | 只收集信息，**不修改数据**，用户察觉不到 | 窃听、流量分析、会话拦截 |
| 主动攻击 | 修改数据流或产生虚假数据流 | DoS / DDoS、篡改、伪装、重放、SQL 注入 |

**二、常见攻击手段**

- **口令破解**：字典攻击、暴力攻击、混合攻击。
- **缓冲区溢出**：输入超长覆盖堆栈，转去执行恶意代码。
- **欺骗攻击**：IP 欺骗、ARP 欺骗、DNS 欺骗、源路由欺骗。
- **DoS / DDoS**：拒绝服务，SYN Flood、Smurf、Ping of Death。
- **SQL 注入**：在输入中插入 SQL 命令，**首要目标是获得数据库权限**。
- **网络蠕虫**：利用网络和邮件传播，**不寄生文件**（红色代码、尼姆达、震网）。
- **木马**：隐藏在正常程序中的后门，**基于远程控制**，有隐蔽性和非授权性。

**三、加密算法对比**

| 类型 | 密钥 | 算法 |
|---|---|---|
| 对称加密（私钥） | 加密解密**同一把密钥** | DES、3DES、AES、IDEA、RC5 |
| 非对称加密（公钥） | 公钥加密、私钥解密（保密）；私钥签名、公钥验签（签名） | RSA、DSA、ECC |
| 消息摘要（散列） | 无密钥，单向不可逆 | MD5（128 位）、SHA |

- **DES**：共享密钥（对称）。
- **AES**：分组加密（对称），支持 128 / 192 / 256 位密钥。
- **MD5**：输出 128 位散列值，用于完整性校验。

## 2.7 认证技术、SSL、防火墙与 IDS / IPS

**一、身份认证方式安全性排序**

生物认证 ≈ 双因子（U 盾）> 动态口令（OTP，一次一密）> 静态口令（最不安全）。

**二、PKI 公钥基础设施**

- 核心元素：**数字证书**。
- 核心执行者：**CA 认证中心**（第三方可信机构）。
- 6 种服务：身份认证、数据完整性、保密性、公正性、不可抵赖、时间戳。

**三、数字签名**

- 过程：发送方用**自己的私钥**对消息摘要加密 → 接收方用发送方**公钥**解密。
- 三大功效：**真实性、完整性、不可抵赖性**。

**四、SSL / HTTPS**

- SSL：位于**传输层与应用层之间**，基于 TCP。
- HTTPS = HTTP + SSL，默认端口 **443**（HTTP 是 80）。
- 原理：用**对称密钥**加密数据，用**非对称算法**交换对称密钥。

**五、防火墙**

网络三区（受保护程度从低到高）：**外网 < DMZ（周边非军事区）< 内网**。

| 防火墙类型 | 工作层 | 特点 |
|---|---|---|
| 包过滤防火墙 | 网络层 | 检查 IP / 端口，速度快、透明；不能识别应用层内容 |
| 应用代理网关 | 应用层 | 完全隔断内外网直接通信；检查能力强，速度慢 |
| 复合型 | 综合两者 | 兼顾灵活与安全 |

**六、IDS vs IPS**

| 对比项 | IDS 入侵检测 | IPS 入侵防御 |
|---|---|---|
| 工作方式 | **旁路检测**，只报警 | **串接在线**，主动阻断 |
| 功能 | 发现攻击、报告 | 检测 + **实时拦截** |
| 比喻 | 监控摄像头 | 自动灭火器 |

## 2.8 信息安全属性与保护等级

**一、信息安全五属性**

| 属性 | 含义 |
|---|---|
| 机密性（保密性） | 不泄露给未授权者 |
| 完整性 | 未经授权不能修改，能发现被篡改 |
| 可用性 | 授权者需要时能访问 |
| 可控性 | 控制信息流向和行为 |
| 不可否认性（不可抵赖） | 发送方不能否认发送过 |

**二、计算机系统安全保护等级（GB 17859）**

从低到高五级：**自主保护级 → 系统审计保护级 → 安全标记保护级 → 结构化保护级 → 访问验证保护级**。
