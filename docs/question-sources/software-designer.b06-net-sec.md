# 软件设计师（中级）考点精讲（计算机网络与信息安全）

## 6.1 网络体系结构：OSI 与 TCP/IP 各层及设备

OSI 参考模型分为七层，从下到上依次是物理层、数据链路层、网络层、传输层、会话层、表示层和应用层。物理层传输比特流，数据链路层传输帧并负责差错检测和介质访问控制，网络层负责路由选择和分组转发，传输层提供端到端的可靠或不可靠传输，会话层管理会话，表示层负责数据格式转换、加密和压缩，应用层为应用程序提供网络服务。TCP/IP 参考模型分为网络接口层、网际层、传输层和应用层四层。各层的数据单元依次为：物理层是比特，数据链路层是帧，网络层是分组，传输层是段。常见网络设备与层次对应：中继器和集线器工作在物理层，网桥和交换机工作在数据链路层，路由器工作在网络层，网关可以工作在传输层以上。集线器连接的所有设备处于同一个冲突域，交换机的每个端口是一个独立的冲突域，路由器的每个接口是一个独立的广播域。

## 6.2 物理层与数据链路层：以太网、交换机与 VLAN

以太网采用 CSMA/CD 协议控制介质访问，先听后发、边发边听、冲突停发、随机延迟后重发。为保证能检测到冲突，以太网规定最小帧长为 64 字节，最大帧长为 1518 字节。以太网 MAC 地址为 48 位，通常用 12 位十六进制数表示。交换机根据 MAC 地址转发帧，通过自学习建立 MAC 地址表，对未知目的地址的帧采用泛洪。VLAN（虚拟局域网）把一个物理局域网在逻辑上划分为多个广播域，VLAN 间通信需要三层设备，IEEE 802.1Q 是 VLAN 的标准。生成树协议（STP）用于在有冗余链路的交换网络中避免环路。PPP 是点对点链路上常用的数据链路层协议，用于拨号和专线接入。常用编码方式有曼彻斯特编码和差分曼彻斯特编码，曼彻斯特编码每个比特中间都有跳变，用于以太网。

## 6.3 IP 地址：分类、特殊地址与私有地址

IPv4 地址长 32 位，通常用点分十进制表示，分为网络号和主机号两部分。传统 IP 地址分为五类：A 类地址第一字节范围为 1 到 126，默认掩码 255.0.0.0；B 类地址第一字节范围为 128 到 191，默认掩码 255.255.0.0；C 类地址第一字节范围为 192 到 223，默认掩码 255.255.255.0；D 类地址第一字节范围为 224 到 239，用于组播；E 类地址第一字节范围为 240 到 255，保留。私有地址包括 10.0.0.0 到 10.255.255.255、172.16.0.0 到 172.31.255.255 和 192.168.0.0 到 192.168.255.255，不能在公网上路由。127.0.0.0 网段为环回地址，用于本机测试。主机号全 0 表示网络地址，主机号全 1 表示该网络的直接广播地址，255.255.255.255 是有限广播地址。169.254.0.0 到 169.254.255.255 是自动私有 IP 地址，主机无法从 DHCP 服务器获取地址时会自动使用。

## 6.4 子网划分、CIDR 与路由聚合

子网掩码用来区分 IP 地址的网络部分和主机部分，掩码中为 1 的位对应网络号和子网号，为 0 的位对应主机号。IP 地址与子网掩码按位相与得到网络地址。无类别域间路由（CIDR）用网络前缀和前缀长度表示，如 192.168.1.0/24 表示前 24 位是网络前缀，对应子网掩码 255.255.255.0。主机位数为 h 时，一个网络可分配的主机地址数是 2 的 h 次方减 2，要去掉全 0 的网络地址和全 1 的广播地址。例如 /24 网络可用主机数为 254，/26 网络可用主机数为 62，/30 网络可用主机数为 2。把一个网络划分成若干子网时，借用 s 位主机位可得到 2 的 s 次方个子网。路由聚合把多个连续的网络合并成一个更大的网络前缀，聚合后的前缀长度等于这些地址的最长公共前缀的位数。例如 192.168.0.0/24 和 192.168.1.0/24 可聚合为 192.168.0.0/23。

## 6.5 路由选择：RIP、OSPF 与 BGP

路由器根据路由表转发分组，路由表项可以静态配置也可以由路由协议动态生成。内部网关协议用于自治系统内部，包括 RIP 和 OSPF；外部网关协议用于自治系统之间，典型是 BGP。RIP 是基于距离向量算法的协议，以跳数作为度量，最大跳数为 15，跳数 16 表示不可达，每 30 秒向邻居广播一次路由表，适合小型网络，收敛较慢。OSPF 是基于链路状态算法的协议，使用 Dijkstra 算法计算最短路径，用开销作为度量，收敛快，适合大型网络，支持区域划分。BGP 是基于路径向量的协议，用于不同自治系统之间交换路由信息，运行在 TCP 之上，端口号为 179。路由器转发时采用最长前缀匹配原则，选择与目的地址匹配前缀最长的路由。默认路由用 0.0.0.0/0 表示。

## 6.6 ARP、ICMP、DHCP 与 NAT

ARP 把 IP 地址解析为 MAC 地址，主机先广播 ARP 请求，目标主机单播 ARP 应答，ARP 缓存保存最近的映射关系。RARP 把 MAC 地址解析为 IP 地址。ICMP 用于传递差错报告和控制信息，ping 命令使用 ICMP 回送请求和回送应答，tracert 通过逐步增大 TTL 来跟踪路径。DHCP 自动为主机分配 IP 地址、子网掩码、网关和 DNS 等参数，使用 UDP 协议，服务器端口 67，客户端端口 68，获取地址的过程为发现、提供、请求和确认。NAT 把内网的私有地址转换为公网地址，使多台内网主机共享一个公网地址访问互联网，NAPT 同时转换端口号。NAT 缓解了 IPv4 地址不足，但破坏了端到端的连接性。

## 6.7 TCP 与 UDP：连接管理与拥塞控制

TCP 是面向连接的、可靠的、基于字节流的传输层协议，提供全双工通信，通过序号、确认应答、超时重传、滑动窗口和拥塞控制保证可靠传输。TCP 建立连接需要三次握手：客户端发送 SYN，服务器回复 SYN 和 ACK，客户端再发送 ACK。TCP 释放连接需要四次挥手：双方各自发送 FIN 并得到 ACK，主动关闭方最后进入 TIME_WAIT 状态。流量控制由接收方通过窗口字段告诉发送方自己的接收能力，控制发送速率，防止接收方缓冲区溢出。拥塞控制防止过多数据注入网络，包括慢开始、拥塞避免、快重传和快恢复四种算法：慢开始阶段拥塞窗口按指数增长，达到慢开始门限后进入拥塞避免阶段，窗口按线性增长，发生超时则门限减半并重新慢开始。UDP 是无连接的、不可靠的传输协议，首部只有 8 字节，开销小、实时性好，适用于视频、语音和 DNS 查询等场合。

## 6.8 应用层协议与常用端口

HTTP 协议默认端口 80，HTTPS 默认端口 443；FTP 使用两个端口，控制连接端口 21，数据连接端口 20；Telnet 端口 23，明文传输；SSH 端口 22，加密远程登录；SMTP 用于发送邮件，端口 25；POP3 用于接收邮件，端口 110；IMAP 用于接收邮件，端口 143；DNS 端口 53，用于域名与 IP 地址之间的转换，查询通常使用 UDP，区域传送使用 TCP；SNMP 端口 161，用于网络管理；TFTP 使用 UDP，端口 69。DNS 采用分层的域名空间，常见资源记录有 A 记录（域名到 IPv4 地址）、AAAA 记录（域名到 IPv6 地址）、MX 记录（邮件交换）、CNAME 记录（别名）和 NS 记录（域名服务器）。HTTP 是无状态协议，常用方法有 GET 和 POST，状态码 200 表示成功，404 表示资源不存在，500 表示服务器内部错误。

## 6.9 IPv6、无线网络与网络规划管理

IPv6 地址长 128 位，用冒号分隔的八组十六进制数表示，每组 16 位，可以用双冒号压缩连续的全零组，但双冒号在一个地址中只能出现一次。IPv6 解决了 IPv4 地址不足的问题，取消了广播，增加了任播，首部固定为 40 字节，支持自动配置并内置对 IPsec 的支持。IPv4 向 IPv6 过渡的技术有双协议栈、隧道和协议转换。无线局域网标准是 IEEE 802.11 系列，介质访问控制采用 CSMA/CA，802.11b 工作在 2.4GHz 频段，802.11a 工作在 5GHz 频段，802.11n 同时支持 2.4GHz 和 5GHz。网络规划设计常用三层结构：核心层负责高速转发，汇聚层负责策略和路由汇聚，接入层负责终端接入。网络管理的 SNMP 协议由管理站、代理和管理信息库（MIB）组成。

## 7.1 信息安全的基本概念与攻击类型

信息安全的基本属性是机密性、完整性和可用性，此外还有真实性、不可否认性和可控性。机密性是信息不被泄露给未授权者，完整性是信息不被未授权地篡改，可用性是授权用户需要时能访问信息。安全威胁分为被动攻击和主动攻击：被动攻击如窃听、流量分析，不改变数据，难以检测但可以预防；主动攻击如篡改、伪造、重放、拒绝服务，会改变数据或数据流，难以预防但可以检测。重放攻击是攻击者截获合法数据后重新发送以欺骗接收方，可用时间戳、序列号或一次性随机数防御。中间人攻击是攻击者介于通信双方之间，窃听或篡改通信内容。常见的安全措施包括加密、认证、访问控制、防火墙和审计等。

## 7.2 对称加密、非对称加密与哈希算法

对称加密使用同一个密钥进行加密和解密，速度快，适合加密大量数据，缺点是密钥分发和管理困难，典型算法有 DES、3DES、AES 和 RC4。DES 的密钥长度为 56 位，分组长度为 64 位；AES 分组长度为 128 位，密钥长度可为 128、192 或 256 位，是目前广泛使用的对称加密标准。非对称加密使用一对公钥和私钥，公钥公开，私钥保密，用公钥加密的数据只能用私钥解密，速度慢，适合加密少量数据和密钥交换，典型算法有 RSA、ECC 和 Diffie-Hellman。RSA 的安全性基于大整数分解的困难性。哈希算法把任意长度的消息变成固定长度的摘要，具有单向性、抗碰撞性和雪崩效应，MD5 摘要长度为 128 位，SHA-1 摘要长度为 160 位，SHA-256 摘要长度为 256 位。实际应用中常把对称加密与非对称加密结合，用非对称加密传递对称密钥，再用对称加密传输数据。

## 7.3 数字签名、数字证书与 PKI

数字签名用发送方的私钥对消息摘要进行加密。之所以对消息摘要而不是整个消息签名，是因为摘要长度固定且较短，非对称运算速度慢，签名摘要效率更高。接收方用发送方的公钥解密并与自己计算的摘要比较，用于保证消息的完整性、发送方身份认证和不可否认性，但不保证机密性。要同时保证机密性，需要再用接收方的公钥加密。数字证书由证书颁发机构（CA）签发，包含持有者身份、公钥、有效期、颁发者和 CA 的数字签名等信息，遵循 X.509 标准，用来证明公钥属于某个实体。验证证书时用 CA 的公钥验证证书上的签名。公钥基础设施（PKI）由 CA、注册机构（RA）、证书库和证书撤销列表（CRL）等组成，提供证书的签发、管理和撤销服务。证书过期或私钥泄露后，证书会被加入证书撤销列表。报文认证码（MAC）使用共享密钥对消息计算认证码，用来验证消息完整性和来源。

## 7.4 网络安全技术：防火墙、IDS/IPS、VPN 与 SSL

防火墙位于内外网之间，根据安全策略控制进出网络的数据。包过滤防火墙工作在网络层和传输层，根据源和目的 IP 地址、端口、协议等规则过滤；状态检测防火墙跟踪连接状态；应用代理防火墙工作在应用层，安全性高但性能较低。DMZ 用于放置对外提供服务的服务器，位于内外网之间。入侵检测系统（IDS）监视网络和系统活动，发现攻击后告警，属于被动检测；入侵防御系统（IPS）可以在发现攻击时主动阻断，部署在数据通路上。VPN 在公共网络上建立加密的专用通道，常用协议有 IPSec、L2TP、PPTP 和 SSL VPN。IPSec 工作在网络层，包含认证头 AH 和封装安全载荷 ESP 两个协议，ESP 可同时提供加密和认证，AH 只提供认证；IPSec 有传输模式和隧道模式。SSL/TLS 工作在传输层与应用层之间，用于保护 HTTP 等应用，HTTPS 就是 HTTP 加上 SSL/TLS。

## 7.5 恶意代码与常见网络攻击

计算机病毒是能自我复制并破坏系统的程序，需要寄生在宿主文件中；蠕虫不需要宿主，通过网络自我传播；木马伪装成正常程序，用于窃取信息或远程控制，不具备自我复制能力；勒索软件加密用户文件并索要赎金。拒绝服务攻击使服务器无法响应正常请求，分布式拒绝服务攻击利用大量傀儡机同时发起攻击。SYN 洪泛攻击利用 TCP 三次握手，发送大量 SYN 请求而不完成握手，耗尽服务器的连接资源。SQL 注入是在输入中插入 SQL 代码欺骗数据库执行，防御方法是使用参数化查询并过滤输入。跨站脚本攻击（XSS）把恶意脚本注入网页，在其他用户浏览器中执行，防御方法是对输出进行转义。跨站请求伪造（CSRF）利用用户已登录的身份诱使其提交非本意的请求，可用令牌防御。ARP 欺骗通过伪造 ARP 应答篡改他人 ARP 缓存，实现中间人攻击。缓冲区溢出攻击通过向缓冲区写入超长数据覆盖相邻内存。

## 7.6 访问控制、身份认证、等级保护与容灾备份

访问控制模型主要有自主访问控制（DAC）、强制访问控制（MAC）和基于角色的访问控制（RBAC）。DAC 由资源所有者决定谁可以访问，灵活但安全性较低；MAC 由系统根据安全标签强制实施，安全性高，常用于军事系统；RBAC 先给角色分配权限，再给用户分配角色，便于大型组织的权限管理。身份认证的方式有所知（口令）、所有（令牌、智能卡）和所是（指纹、人脸等生物特征），同时使用两种以上称为多因素认证。Kerberos 是基于票据的网络认证协议，使用对称加密，由认证服务器和票据授予服务器组成。我国信息安全等级保护制度把信息系统分为五级，第一级为自主保护级，第五级为专控保护级。容灾备份的两个关键指标是恢复点目标 RPO 和恢复时间目标 RTO：RPO 表示可容忍丢失多少数据，RTO 表示灾难后多长时间内恢复业务。
