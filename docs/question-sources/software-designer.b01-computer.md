# 软件设计师（中级）考点精讲（计算机系统基础）

## 1.1 数据表示：进制转换与原码、反码、补码、移码

计算机内部用二进制表示数据。二进制转十进制按位权展开求和，十进制整数转二进制用除 2 取余法，余数从下往上排列；十六进制每一位对应四位二进制，八进制每一位对应三位二进制。机器数的符号位用 0 表示正、1 表示负。正数的原码、反码、补码都与真值相同。负数的原码是符号位为 1、数值位不变；负数的反码是在原码基础上符号位不变、数值位按位取反；负数的补码是反码末位加 1。n 位二进制补码的表示范围是 -2 的 n-1 次方到 2 的 n-1 次方减 1，8 位补码的范围是 -128 到 127；n 位原码和反码的表示范围关于 0 对称，8 位范围是 -127 到 127。原码和反码中 0 有 +0 和 -0 两种表示，补码中 0 的表示是唯一的。移码是把补码的符号位取反得到的，常用于表示浮点数的阶码，移码中 0 的表示也是唯一的。补码的好处是可以把减法转换为加法，符号位可以和数值位一起参与运算。

## 1.2 数据表示：浮点数、定点数与逻辑运算

定点数的小数点位置固定，定点整数的小数点在最低位之后，定点小数的小数点在符号位和最高数值位之间。浮点数由阶码和尾数两部分组成，基数为 2 时数值等于尾数乘以 2 的阶码次方，阶码决定数的范围，尾数的位数决定数的精度。浮点数的尾数通常用补码或原码表示，阶码常用移码表示。为了在尾数位数固定时保留尽可能多的有效数字，浮点数需要规格化，规格化后原码尾数的最高数值位为 1。浮点数相加减时，先对阶再进行尾数运算，对阶的原则是小阶向大阶看齐，即阶码小的数尾数右移，然后进行尾数加减、规格化和舍入处理。逻辑运算中，与运算当且仅当两个操作数都为 1 时结果为 1，或运算只要有一个为 1 结果就为 1，异或运算两位相同结果为 0、不同结果为 1。

## 1.3 校验码：奇偶校验、CRC 与海明码

校验码通过增加冗余位来检测或纠正传输和存储中的错误。奇偶校验只增加 1 位校验位，使码字中 1 的个数为奇数（奇校验）或偶数（偶校验），只能检测奇数位错误，不能检测偶数位错误，也不能纠错。循环冗余校验码（CRC）用生成多项式对信息位做模 2 除法，所得余数作为校验位附在信息位后发送，接收方用同一多项式去除，余数为 0 则认为没有检出错误；CRC 只能检错，不能纠错，检错能力强，广泛用于网络和磁盘。海明码在数据位中插入多个校验位，能检测并纠正一位错误。设数据位为 k 位、校验位为 r 位，海明码满足 2 的 r 次方大于等于 k + r + 1。校验位放在 2 的幂次位置，即第 1、2、4、8 位等。码距是任意两个合法码字之间不同位数的最小值，码距为 d 的编码可以检测 d-1 位错，纠正 (d-1)/2 向下取整位错。

## 1.4 CPU 的组成与寄存器

CPU 由运算器和控制器组成。运算器包括算术逻辑单元（ALU）、累加寄存器（AC）、数据缓冲寄存器（DR）和状态条件寄存器（PSW）。控制器包括程序计数器（PC）、指令寄存器（IR）、指令译码器、时序部件和操作控制器。程序计数器存放下一条要执行的指令的地址，顺序执行时自动加 1（或加指令长度），遇到转移指令时被改写。指令寄存器存放当前正在执行的指令。地址寄存器（AR）存放要访问的主存单元地址。状态条件寄存器保存运算结果的状态标志，如进位、溢出、零、符号等。CPU 取指令、分析指令和执行指令的过程构成指令周期。

## 1.5 指令系统与寻址方式

一条指令由操作码和地址码两部分组成，操作码指明要执行的操作，地址码指出操作数或操作数的地址。寻址方式是确定操作数地址的方法。立即寻址的操作数直接包含在指令中，速度最快。直接寻址的指令地址码给出的就是操作数的内存地址。间接寻址的地址码给出的是存放操作数地址的单元地址，需要多次访问内存。寄存器寻址的操作数在寄存器中，寄存器间接寻址的寄存器中存放的是操作数的内存地址。相对寻址的有效地址是程序计数器的值加上偏移量，常用于转移指令，便于程序在内存中浮动。基址寻址的有效地址是基址寄存器内容加偏移量，便于程序重定位；变址寻址的有效地址是变址寄存器内容加偏移量，便于处理数组和循环。堆栈寻址的操作数存取遵循后进先出原则，由栈指针指出栈顶。

## 1.6 CISC 与 RISC、Flynn 分类与多核

复杂指令系统计算机（CISC）指令数量多、指令格式和长度不固定、寻址方式多，多使用微程序控制，Intel x86 是典型代表。精简指令系统计算机（RISC）指令数量少、指令格式规整且长度固定、寻址方式少，大量使用寄存器，多使用硬布线控制，只有取数和存数指令访问内存，更适合采用流水线技术，ARM 和 MIPS 是典型代表。Flynn 分类法按指令流和数据流的数量把计算机分为四类：单指令流单数据流（SISD）、单指令流多数据流（SIMD）、多指令流单数据流（MISD）和多指令流多数据流（MIMD）。传统的单处理机属于 SISD，向量处理机和阵列处理机属于 SIMD，多核处理器和多处理机系统属于 MIMD。多核处理器在一个芯片上集成多个处理器核心，通过并行执行提高性能。

## 1.7 指令流水线

指令流水线把一条指令的执行分成若干个阶段，让多条指令的不同阶段在时间上重叠执行，从而提高吞吐率。经典的五段流水线包括取指、译码、执行、访存和写回。流水线的周期取决于最慢的那一段的执行时间。设流水线有 k 段，每段时间都是 Δt，连续执行 n 条指令，则总时间为 (k + n - 1)Δt，而顺序执行需要 nkΔt。吞吐率是单位时间内完成的指令数，实际吞吐率 = n / ((k + n - 1)Δt)，最大吞吐率为 1/最慢段时间。加速比是不使用流水线的执行时间与使用流水线的执行时间之比，段数越多、指令数越多，加速比越接近段数 k。流水线冒险分为结构冒险、数据冒险和控制冒险三类：结构冒险是硬件资源冲突，数据冒险是后面的指令需要前面指令的结果，控制冒险由转移指令引起。

## 1.8 存储系统：层次结构、RAM 与 ROM、编址计算

计算机存储系统分为寄存器、Cache、主存、辅存几个层次，越靠近 CPU 速度越快、容量越小、单位价格越高。存储系统采用层次结构是依据程序访问的局部性原理，包括时间局部性和空间局部性。主存由 RAM 和 ROM 组成：RAM 可读写但断电后信息丢失，分为静态 RAM（SRAM）和动态 RAM（DRAM），SRAM 速度快、不需要刷新、集成度低，常用作 Cache，DRAM 需要定期刷新、集成度高，常用作主存；ROM 断电后信息不丢失，包括 PROM、EPROM、EEPROM 和闪存。存储器按字节编址时，地址范围从 A 到 B（十六进制）的存储容量为 B - A + 1 字节。例如地址从 4000H 到 7FFFH 共有 4000H 个字节，即 16KB。构成存储器时，所需芯片数 = 总容量 / 单个芯片容量。

## 1.9 Cache：映射方式、替换算法与平均访问时间

Cache 位于 CPU 和主存之间，用来缓解两者速度差距，由硬件自动管理，对程序员透明。CPU 访问存储器时，要访问的数据在 Cache 中称为命中，否则称为未命中。设 Cache 命中率为 h，Cache 访问时间为 t1，主存访问时间为 t2，则平均访问时间 = h × t1 + (1 - h) × t2。主存与 Cache 之间的地址映射方式有三种：直接映射、全相联映射和组相联映射。直接映射每个主存块只能放到 Cache 中唯一确定的一行，硬件简单但冲突率高；全相联映射允许主存块放到任意 Cache 行，冲突率最低但地址比较电路复杂、成本高；组相联映射把 Cache 分成若干组，主存块先映射到固定的组，再在组内任意放置，是前两种方式的折中。Cache 已满需要替换时，常用的替换算法有先进先出（FIFO）、最近最少使用（LRU）和随机替换。Cache 的写策略分为写直达和写回：写直达同时写 Cache 和主存，写回只写 Cache，块被替换时才写回主存。

## 1.10 总线与 I/O 控制方式

总线是计算机各部件之间传输信息的公共通路，按传输内容分为数据总线、地址总线和控制总线。数据总线的宽度决定一次能传输的数据位数，地址总线的宽度决定可直接寻址的内存空间大小，n 位地址总线可寻址 2 的 n 次方个存储单元。常见的 I/O 控制方式有程序查询方式、中断方式和 DMA 方式。程序查询方式下 CPU 不断查询外设状态，CPU 利用率最低。中断方式下外设准备好后向 CPU 发出中断请求，CPU 响应中断后保存现场、执行中断服务程序，处理完毕再恢复现场并返回，CPU 与外设可以并行工作。DMA（直接存储器访问）方式由 DMA 控制器直接在外设和内存之间传送数据，只在传送开始和结束时才需要 CPU 参与，适合高速、批量的数据传输。通道方式是更高级的 I/O 控制方式，由专门的 I/O 处理机管理输入输出。

## 1.11 系统可靠性：串联、并联与可用性

系统可靠性用平均无故障时间（MTBF）和平均修复时间（MTTR）来衡量，可用性等于 MTBF 除以 MTBF 与 MTTR 之和。串联系统由若干部件串联而成，只要有一个部件失效整个系统就失效，设各部件的可靠度为 R1、R2、……、Rn，则系统可靠度 R = R1 × R2 × …… × Rn。并联系统只有所有部件都失效系统才失效，系统可靠度 R = 1 - (1 - R1)(1 - R2)…(1 - Rn)。串联系统的可靠度低于任何一个部件，并联系统的可靠度高于任何一个部件。采用冗余可以提高可靠性，如三模冗余（TMR）通过多数表决屏蔽单个部件的故障。

## 1.12 磁盘与 RAID

磁盘的存取时间由寻道时间、旋转延迟时间和数据传输时间三部分组成，其中寻道时间指磁头移动到目标磁道所需时间，旋转延迟指目标扇区转到磁头下所需时间，平均旋转延迟为磁盘旋转半周的时间。磁盘容量等于磁头数乘以磁道数乘以每道扇区数乘以每扇区字节数。RAID 通过多块磁盘组合提高性能或可靠性。RAID 0 采用条带化，没有冗余，读写速度快但任何一块盘损坏都会丢失数据；RAID 1 采用磁盘镜像，可靠性高，磁盘利用率为 50%；RAID 5 把数据和奇偶校验信息分布存放在各个磁盘上，最少需要 3 块盘，允许坏 1 块盘，利用率为 (n-1)/n；RAID 6 用两份校验信息，允许同时坏 2 块盘。

## 1.13 嵌入式系统基础

嵌入式系统是以应用为中心、以计算机技术为基础，软硬件可裁剪，适应应用系统对功能、可靠性、成本、体积和功耗严格要求的专用计算机系统。嵌入式系统一般由嵌入式处理器、外围设备、嵌入式操作系统和应用软件组成，常见的嵌入式处理器有微控制器（MCU）、数字信号处理器（DSP）和片上系统（SoC）。嵌入式操作系统具有微型化、可定制、实时性、可靠性高和可移植等特点，常见的有 VxWorks、μC/OS、嵌入式 Linux 和 FreeRTOS。实时系统要求在规定时间内对外部事件做出响应，分为硬实时和软实时，硬实时系统错过截止时间会造成严重后果。
