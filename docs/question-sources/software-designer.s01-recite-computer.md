# 软件设计师（中级）基础知识速记（计算机系统知识）

## 1.1 硬件组成与 CPU

**一、计算机硬件五大部件**：运算器、控制器、存储器、输入设备、输出设备。

**二、CPU 组成**：CPU = 运算器 + 控制器 + 寄存器组 + 内部总线。

> ⚠ 系统总线**不属于** CPU（真题第 11 题）。

**三、运算器组成**

- ALU（算术逻辑单元）
- 累加寄存器（AC）
- 数据缓冲寄存器（DR）
- 状态条件寄存器（PSW）
- 作用：数据加工执行部件，受控制器指挥。

**四、控制器组成**：指令控制逻辑、时序控制逻辑、总线控制逻辑、中断控制逻辑。

**五、重点寄存器**

| 寄存器 | 作用 |
|---|---|
| 程序计数器 PC | 存**下一条**指令的地址；具有计数 + 寄存功能 |
| 指令寄存器 IR | 存**当前**指令 |
| 地址寄存器 MAR | 存要访问的内存地址 |
| 数据缓冲寄存器 MDR | 存与内存交换的数据 |
| 状态条件寄存器 PSW | 存标志位 |

## 1.2 数据表示

**一、原码、反码、补码、移码**

| 码制 | 正数 | 负数 |
|---|---|---|
| 原码 | 符号位 0 + 真值绝对值 | 符号位 1 + 绝对值 |
| 反码 | 与原码相同 | 符号位不变，数值位逐位取反 |
| 补码 | 与原码相同 | 反码末位 + 1 |
| 移码 | 补码符号位取反 | 同左 |

**关键结论**

- 正数：原码 = 反码 = 补码。
- **0 在补码和移码中表示唯一**（原码、反码中 +0 和 -0 不唯一）。
- 补码可把**减法变加法**；符号位可参加运算。
- 移码常用于**浮点数阶码**。
- n 位补码范围：-2^(n-1) ~ 2^(n-1) - 1（比原码、反码多表示一个最小负数）。

**二、定点数**

- **定点整数**：小数点在最低位之后。
- **定点小数**：小数点在最高位之前。

**三、浮点数**

格式：N = 2^E × M。

- **阶码 E**：带符号纯整数，决定数的**表示范围**。
- **尾数 M**：带符号纯小数，决定数的**精度**。

> ⚠ 阶码越长 → 范围越大；尾数越长 → 精度越高。阶码长、尾数短 → 范围大、精度低。

**浮点运算三步**：① 对阶：小阶向大阶看齐，尾数右移；② 尾数相加减；③ 结果规格化。

## 1.3 校验码

**一、码距**

任意两个合法编码至少不同的二进制位数。**码距越大，检错纠错能力越强。**

码距 = 1：无检错能力；码距 = 2：可检 1 位错；码距 ≥ 3：可纠错。

**二、三种校验码对比**

| 校验码 | 校验位 | 检错 | 纠错 | 特点 |
|---|---|---|---|---|
| 奇偶校验 | 加 1 位 | 可检奇数位数错 | ✗ 不能纠错 | 码距 = 2 |
| 海明码 | k 位 | 可检错 + 纠错 | ✓ 纠 1 位错 | 扩大码距 |
| CRC 循环冗余 | 多项式 | 检错 | ✗ 不能纠错 | 模 2 运算，生成多项式最高最低位为 1 |

**三、海明码计算**

- 校验位数 k 满足：2^k ≥ n + k + 1（n 为数据位数）。
- 校验位位置：第 2^i 位（1、2、4、8、16……）。
- 数据位填在其余位置。

## 1.4 指令系统与流水线

**一、常见寻址方式**

| 寻址方式 | 操作数位置 | 访存次数 | 速度 |
|---|---|---|---|
| 立即寻址 | 指令中直接给操作数 | 0 | **最快** |
| 寄存器寻址 | 在寄存器中 | 0（只访问寄存器） | 次快 |
| 直接寻址 | 指令中给操作数地址 | 1 | 较慢 |
| 寄存器间接 | 寄存器中放操作数地址 | 1 | 较慢 |
| 间接寻址 | 地址的地址 | ≥ 2 | 最慢 |

> ⚠ 速度：立即 > 寄存器 > 直接 > 间接。

**二、CISC vs RISC**

| 对比项 | CISC 复杂指令集 | RISC 精简指令集 |
|---|---|---|
| 指令数量 | 多、复杂 | 少，只选高频简单指令 |
| 指令长度 | 不固定 | **固定** |
| 寻址方式 | 多 | **少** |
| 访存指令 | 不限制 | **只有 LOAD / STORE 访存** |
| 通用寄存器 | 较少 | **多** |
| 控制器 | **微程序控制** | **组合逻辑（硬布线）** |
| 流水线 | 多周期一条指令 | **一个周期一条**，流水线 |

**三、指令流水线**

- **流水线周期** = 各段时间中**最长**的那段时间：Δt = max(Δt1, Δt2, …)。
- **执行 n 条指令总时间** = 第 1 条执行时间 + (n - 1) × 流水线周期。
- **最大吞吐率** = 1 / 最长段时间。
- **建立时间** = m × Δt（m 段）。

## 1.5 存储系统：分类、层次与 Cache

**一、存储器分类（按存取方式）**

- **随机存取**（存取时间与地址无关）：RAM、ROM。
- **顺序存取**（与地址有关）：磁带（顺序）、磁盘（直接）。
- RAM 可读可写；ROM 只读。

**二、层次结构（由高到低）**：寄存器 → Cache → 主存 → 辅存。

越往上：容量越小、速度越快、价格越贵。

- Cache ↔ 主存：**全部由硬件**实现。
- 主存 ↔ 辅存（虚拟存储）：**硬件 + 软件（OS）**共同实现。

**三、局部性原理**

- **时间局部性**：刚访问过的很快再访问（循环）。
- **空间局部性**：刚访问的附近地址很快访问（数组）。

**四、Cache 三种地址映像**

| 映像方式 | 对应关系 | 特点 |
|---|---|---|
| 直接映像 | 主存块**只能**固定对应一个 Cache 块 | 冲突多、不灵活、易实现 |
| 全相联映像 | 主存任意块可放 Cache 任意块 | 冲突少、灵活、比较电路多、成本高 |
| 组相联映像 | 组间直接、组内全相联 | 折中 |

- Cache 对程序员**透明**；地址映射由**硬件**自动完成。
- **平均访存时间** = 命中率 × Cache 时间 + (1 - 命中率) × 主存时间。

## 1.6 主存编址与磁盘计算

**一、主存编址计算**

- 按字节编址：每个地址对应 1 字节；按字编址：每个地址对应一个字。
- 地址范围大小 = 末地址 - 首地址 + 1。
- 所需芯片数 = 总容量 ÷ 单片容量。

例：A0000H ~ DFFFFH，按字节编址：大小 = DFFFF - A0000 + 1 = 40000H = 256KB；芯片 32K × 8bit → 256K ÷ 32K = **8 片**。

**二、磁盘**

- **磁道**：盘面同心圆，外圈为 0 道。
- **柱面**：所有盘面相同磁道号的集合（文件尽量放同一柱面，减少寻道）。
- **扇区**：磁道上的分段，最小读写单位。
- **磁盘访问时间** = 寻道时间 + 旋转延迟 + 传输时间。
- 提高密度：道密度（半径方向）、位密度（磁道上）；面密度 = 位密度 × 道密度。

例：磁头移相邻道 2ms，平均移 5 道 → 寻道 10ms；旋转延迟 10ms；传输 1ms；每块共 21ms；100 块 = **2100ms**。

## 1.7 输入输出、中断与 DMA

**一、三种 I/O 控制方式对比**

| 方式 | CPU 与外设 | CPU 效率 | 数据单位 | 适用 |
|---|---|---|---|---|
| 程序查询（程序控制） | 串行，CPU 踏步等待 | 最低 | 字 | 简单外设 |
| 中断方式 | 并行准备，数据交换时 CPU 介入 | 中 | 字 | 中低速 |
| DMA 方式 | 主存与外设直接成块传送，CPU 仅在首尾干预 | 最高 | **数据块** | 高速外设 |

**二、中断**

- 中断响应：外设准备好后发出中断请求 → CPU **保护现场** → 执行中断服务程序 → **恢复现场**返回。
- **中断向量** = 中断服务程序的**入口地址**（存在中断向量表中）。
- 保护现场的目的：能正确返回被中断的程序。

**三、DMA**

- 数据在主存与 I/O 间**直接成块**传送，不需 CPU 干预。
- DMA 与 CPU 同时访存时，CPU 让出总线，称为**周期挪用 / 周期窃取**（占用一个存取周期）。
- 三种方式：停止 CPU 访存、周期挪用、DMA 与 CPU 交替访问。

## 1.8 总线与可靠性计算

**一、总线按层次分类**

| 总线 | 位置 | 例子 |
|---|---|---|
| 片内总线 | 芯片内部 | CPU 内部寄存器与 ALU 间 |
| 系统总线 | 主板上各大部件间 | CPU、主存、I/O 接口之间 |
| 外部总线 | 设备一级 | RS-232、SCSI、USB |

**二、系统总线三类**

- **数据总线**：传数据，宽度决定一次传位数。
- **地址总线**：传地址，宽度决定寻址空间。
- **控制总线**：传控制信号。

代表：ISA、EISA、PCI（并行）。USB：通用串行总线，即插即用、热插拔。

> ⚠ 系统总线用于连接**主存及外设部件**（CPU 通过 I/O 接口）。

**三、可靠性基本概念**

- **可靠性 R(t)**：t 时刻正常运行的概率。
- **MTBF**：平均无故障时间（两次故障间平均正常工作时间）。
- **MTTR**：平均修复时间（有的资料写作 MTRF）。
- **可用性 A**：任意时刻能正常工作的概率。

**四、串联与并联系统**

- **串联系统**：所有子系统都正常，系统才正常：R = R1 × R2 × … × Rn（串联越多，可靠性越低）。
- **并联系统**：只要有一个正常，系统就正常：R = 1 - (1 - R1)(1 - R2)…(1 - Rn)（并联越多，可靠性越高）。
