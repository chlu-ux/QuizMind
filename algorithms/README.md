# 软件设计师 · 算法题代码

软件设计师下午题常考的算法，用 C 语言（与考试可选语言一致）实现。每个文件独立可运行：

- 文件头注释：算法思想、递推式 / 步骤、复杂度、**考点**（含高频易错点）；
- 代码行内注释：关键语句为什么这样写，哪些位置是真题填空题爱挖的；
- `main`：带用例并用 `CHECK` 断言结果，注释里的手算结论都经过程序验证。

- 填空标记：代码里形如 `/* 【填空①】… */` 的位置，是真题里最常被挖成填空的语句
  （循环边界、比较符号、递推式、递归出口、下标 ±1、赋值方向等）。
  复习时可以遮住这些行，自己默写再对照。查看全部标记：`grep -n "填空" *.c`。

```bash
make test        # 编译并运行全部
make build/09-dijkstra && ./build/09-dijkstra   # 单个
make clean
```

## 考点速查

### 四大算法设计策略怎么区分

| 策略 | 核心特征 | 典型题 |
| --- | --- | --- |
| 分治 | 分解成**相互独立**的同类子问题，递归求解后合并；无重叠子问题 | 快排、归并、折半查找、汉诺塔、最大子段和 |
| 动态规划 | **最优子结构 + 重叠子问题**，自底向上填表保存子问题解 | 0-1 背包、LCS、矩阵连乘、Floyd |
| 贪心 | **贪心选择性质 + 最优子结构**，每步取局部最优，不回头 | 部分背包、Huffman、活动安排、Prim/Kruskal、Dijkstra |
| 回溯 | 解空间树上深度优先 + 剪枝，求所有解 / 可行解 | N 皇后、图着色、0-1 背包（回溯解法）、哈密顿回路 |

分支限界法与回溯的区别：广度优先 / 最小耗费优先，求**最优解**。

### 排序算法对比（高频选择题）

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
| --- | --- | --- | --- | --- |
| 直接插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 简单选择 | O(n²) | O(n²) | O(1) | 不稳定 |
| 希尔 | 约 O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 快速 | O(n log n) | **O(n²)** | O(log n) | 不稳定 |
| 堆 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 归并 | O(n log n) | O(n log n) | **O(n)** | 稳定 |

### 容易混淆的几组

- Dijkstra（单源、贪心、不允许负权）vs Floyd（多源、动态规划、允许负权但无负环）；
- Prim（加点、O(n²)、稠密图）vs Kruskal（加边、O(e log e)、稀疏图）；
- 0-1 背包（动态规划）vs 部分背包（贪心）；
- 最长公共**子序列**（可不连续）vs 最长公共**子串**（必须连续）；
- 主定理：`T(n) = aT(n/b) + f(n)`，比较 `f(n)` 与 `n^(log_b a)`，二者同阶时 `T(n) = Θ(f(n)·log n)`。
